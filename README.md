# PA自动测试系统 GUI版本

## 概述

这是一个基于PySide6的功放自动测试系统GUI版本，将原有的命令行测试脚本转换为用户友好的图形界面应用。

## 主要功能

### 1. 仪器配置和连接
- **仪器地址配置**: 配置信号发生器、频谱分析仪和电源的VISA地址
- **测试参数配置**: 设置测试频率、功率范围、压缩点等参数
- **自动连接**: 一键连接所有测试仪器
- **配置保存**: 保存当前配置到config.json文件

### 2. 线损测量
- **连接引导**: 提供详细的连接说明和示意图
- **两步测量**: 
  - 路径1: 信号源 → 线缆① → 衰减器 → 线缆② → 频谱仪
  - 路径2: 信号源 → 线缆① → 线缆③ → 线缆④ → 衰减器 → 线缆② → 频谱仪
- **自动计算**: 自动计算各线缆的损耗值
- **结果显示**: 以表格形式显示所有频率点的线损结果

### 3. 驱动功放映射
- **连接引导**: 显示驱动功放测试连接图
- **功率映射**: 测量信号源输入功率与驱动功放输出功率的映射关系
- **实时可视化**: 在测量过程中实时显示功率映射曲线
- **数据保存**: 自动保存映射数据供后续主功放测试使用

### 4. 主功放测试
- **完整测试**: 支持有驱动和无驱动两种模式
- **安全保护**: 设置DUT最大输入功率保护，防止器件损坏
- **压缩点检测**: 自动检测1dB/3dB/5dB压缩点
- **实时监控**: 
  - 输入vs输出功率曲线
  - 输出功率vs增益曲线
  - 输出功率vs效率曲线
  - DC功耗监控
- **紧急停止**: 提供紧急停止功能确保测试安全

### 5. 数据可视化
- **多频率对比**: 同时显示多个频率点的性能曲线
- **饱和特性**: 分析各频率点的饱和输出功率、增益和效率
- **交互式图表**: 支持缩放、平移等交互操作
- **报告生成**: 自动生成HTML格式的测试报告

### 6. 数据导出
- **多格式支持**: 支持JSON、CSV、PDF格式导出
- **文件管理**: 显示所有测试数据文件及修改时间
- **快速导出**: 一键导出选中的测试数据

### 7. 实时日志
- **测量进度**: 实时显示测量进度条
- **状态日志**: 显示详细的测量状态和错误信息
- **时间戳**: 所有日志条目都包含时间戳

## 技术特性

### 多线程设计
- **主线程隔离**: 所有耗时的测量任务都在独立的工作线程中运行
- **UI响应**: 确保用户界面始终保持响应状态
- **安全停止**: 支持安全的线程停止机制

### 实时数据更新
- **进度回调**: 实时更新测量进度
- **数据流**: 支持实时数据流更新图表
- **状态同步**: 工作线程与UI线程的状态同步

### 用户体验
- **连接图示**: 提供清晰的连接示意图
- **确认对话框**: 在关键操作前进行确认
- **错误处理**: 完善的错误处理和用户提示
- **现代UI**: 采用Fusion样式和自定义样式表

## 安装和使用

### 环境要求
```bash
conda activate VISA_demo
```

### 必需的Python包
- PySide6 >= 6.6.0
- matplotlib >= 3.10.0
- numpy >= 1.26.4
- pandas >= 2.3.1
- seaborn >= 0.13.2
- PyVISA >= 1.14.1

### 启动方法

#### 方法1: 使用批处理文件
```bash
双击运行 start_gui.bat
```

#### 方法2: 命令行启动
```bash
conda activate VISA_demo
python enhanced_main_gui.py
```

## 使用流程

### 1. 系统配置
1. 打开"仪器配置"选项卡
2. 填入所有仪器的VISA地址
3. 设置测试参数（频率、功率范围等）
4. 点击"保存配置"
5. 点击"连接仪器"测试连接

### 2. 线损测量
1. 打开"线损测量"选项卡
2. 查看连接说明和示意图
3. 按提示连接路径1
4. 点击"开始线损测量"
5. 根据提示重新连接路径2
6. 等待测量完成，查看结果

### 3. 驱动映射（如果启用驱动模式）
1. 打开"驱动映射"选项卡
2. 查看连接说明
3. 确认驱动功放已正确供电和连接
4. 点击"开始驱动映射"
5. 观察实时测量曲线

### 4. 主功放测试
1. 打开"功放测试"选项卡
2. 查看连接说明
3. 确认所有设备正确连接和供电
4. 点击"开始功放测试"
5. 观察实时测量数据
6. 如需要可点击"紧急停止"

### 5. 数据分析
1. 打开"数据可视化"选项卡
2. 加载测试数据文件
3. 查看分析图表
4. 生成测试报告

### 6. 数据导出
1. 打开"数据导出"选项卡
2. 刷新文件列表
3. 选择要导出的文件
4. 选择导出格式进行导出

## 注意事项

### 安全事项
- 在进行任何连接操作前，确保所有设备已断电
- 设置合适的DUT最大输入功率保护值
- 测试过程中如发现异常立即使用紧急停止功能
- 定期检查线缆连接是否牢固

### 测量精度
- 确保所有连接器清洁无腐蚀
- 使用高质量的RF线缆
- 在测量前预热仪器至少30分钟
- 环境温度保持稳定

### 故障排除
- 如果仪器连接失败，检查VISA地址是否正确
- 如果测量数据异常，检查线缆连接
- 如果GUI无响应，可能是测量任务卡住，重启应用
- 如果图表显示异常，检查测试数据文件格式
