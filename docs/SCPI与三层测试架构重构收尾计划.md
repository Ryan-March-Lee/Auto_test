# SCPI 与三层测试架构重构收尾计划

## 1. 文档目的与当前结论

本文件合并原《SCPI 控制架构重构指南》和《三层测试架构重构计划》，作为阶段 8 的唯一执行与验收清单。

合并是合理的：SCPI 架构迁移和三层测试迁移共享同一条验收链路，任何生产入口切换都必须同时通过 Unit、Simulation 和受控 Hardware smoke。历史阶段记录只保留事实依据，不在本文件重复展开。

截至 2026-10-01，阶段 0 至 7 的离线能力、现代 GUI 的主要端口注入路径、新应用组装路径的 `minimal_action` 现场验收已经完成；阶段 8 已完成最终离线回归，但真实三类测量验收和现场门槛仍未闭合。当前默认硬件边界明确为：

```text
应用入口 / 测量服务
        ↓
measurement_port
        ↓
SafetyInstrumentSession
        ↓
driver
        ↓
transport
        ↓
VISA 或仿真设备
```

`SafetyInstrumentSession` 负责默认硬件路径的连接状态、安全顺序和资源清理；独立 `action`/`flow` 作为可复用安全组件保留。除非后续验收证明必须改变该边界，否则不把“工厂必须逐个实例化 action/flow”作为额外重构目标。

### 步骤 2：完成三类测量的真实应用验收

按低风险到高风险顺序执行 `cable loss`、`driver power mapping`、`amplifier measurement`。每种类型先执行离线 Unit/Simulation，再在现场授权后执行应用默认组装路径，不使用独立旧入口替代。

**每种测量的执行步骤**

1. 检查配置、设备身份、空载状态、动作预算和安全功率。
2. 通过 `app.gui_runtime.connect_instruments()` 组装 `transport -> driver -> SafetyInstrumentSession -> measurement_port`；实际生产流程使用明确的电源角色、通道和上下电顺序，不复用 smoke 的逐台探测语义作为生产拓扑。
3. 执行最小可代表性动作，记录真实 SCPI 操作顺序、测量值、设备身份和动作次数。
4. 验证完成、异常、取消三条路径都立即关闭 RF，按 `Drain -> Gate` 关闭电源，再释放 VISA resource 和 ResourceManager。
5. 保存脱敏报告和配置快照；现场原始敏感资料只保存在本机。

**必须覆盖的验收点**

- 线损：频率/功率单位、线损数据读取、测量结果和范围边界。
- 驱动映射：驱动功放通道、DUT 通道、功率扫描顺序及异常中止。
- 主功放：功放计算使用纯计算模块，输入输出单位和安全停机行为正确。
- 所有类型：重复测量不会使用已清理端口；失败或取消后可重新连接并测量。

**通过标准**

- 三类测量均由新应用组装路径完成，并有独立报告。
- 设备最终处于 RF 关闭、所有电源输出关闭、连接资源释放状态。
- 新旧实现的命令、单位、日志、异常、取消和清理差异均有解释；不得以一次 `minimal_action` 报告代替完整测量验收。

## 4. 最终验收门槛

只有以下条件全部满足，才能宣布重构完成：

1. 三类完整测量均由新应用组装路径完成真实验收，并有脱敏现场证据。
2. 默认硬件路径使用已确认的 `SafetyInstrumentSession` 协调边界，或有新的架构决定及等价安全测试。
3. smoke 的逐台多电源探测语义已经写入规范；生产电源拓扑、角色、通道、上下电顺序、功放供电条件和设备映射均已在正式测量逻辑中确认并写入规范。
4. 所有生产调用方均经过组装层，服务层没有 VISA、SCPI 或 GUI 依赖。
5. GUI 端口所有权闭合，完成、异常、取消、停止、部分初始化和重复测量均不会复用已清理端口。
6. legacy 入口已经删除，或全部明确标记为兼容适配器并具备移除条件。
7. Unit、Simulation、全量离线测试、应用检查和必要 Hardware smoke 全部通过，无未解释回归。
8. 现场配置、地址、凭据和敏感报告未进入版本库。

## 5. 长期规则

- 每次提交运行 `./run_tests.ps1`；修改 transport、driver、action、flow、配置或清理逻辑时额外运行相关 Unit/Simulation 测试。
- 涉及真实设备控制、SCPI、时序或硬件配置的变更，评估并安排受控 Hardware smoke；硬件测试不得进入默认发现和 CI。
- 离线和模拟测试不得访问真实网络、VISA resource 或真实地址。
- 普通设置动作不得隐式开启 RF 或电源；所有异常、取消、部分初始化和程序退出路径必须执行可重复的安全清理。
- 频谱仪资源关闭不等于面板已恢复 Local 状态；如现场要求 Local，应单独定义并验收该行为。
- 现场运行保留本机日志、脱敏配置快照、软件版本和设备身份；失败时先保存现场，再区分软件、网络、设备和配置问题。
