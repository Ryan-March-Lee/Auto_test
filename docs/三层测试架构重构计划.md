# 三层测试架构重构计划

## 目标与当前结论

测试分为三层：

1. **Unit**：离线单元测试，不访问真实网络或 VISA。
2. **Simulation**：使用模拟设备验证完整流程、故障和清理。
3. **Hardware smoke**：通过独立门禁验证真实设备，禁止进入默认测试发现和 CI。

阶段 0 至 7 的基础能力及现代 GUI 的主要端口注入路径已落地；2026-09-30 独立 `minimal_action` 入口完成一次受限动作并通过安全清理。动态电源发现已接入新应用组装器，并完成现场连接及立即安全关闭验证。阶段 8 尚未完成：默认硬件工厂尚未真正组装独立 action/flow，历史测量类仍可隐式创建旧控制器，GUI 清理后的端口生命周期未闭合，按具体测量类型执行完整应用动作、现场记录归档和旧实现最终处置待完成。

历史实施细节见阶段完成记录；本计划只保留当前状态、剩余工作和验收门槛。

## 长期运行规则

- 每次提交运行 `./run_tests.ps1`；修改 transport、driver、action、flow、配置或清理逻辑时另跑相关 Unit/Simulation 测试。
- 涉及真实设备控制、SCPI、时序或硬件配置的变更，评估并安排相应真实 smoke；硬件测试不加入默认发现和 CI。
- 离线与模拟测试不得访问真实网络、VISA resource 或真实地址。
- 普通设置动作不得隐式开启 RF 或电源；异常、取消、部分初始化和退出路径都必须执行可重复的安全清理。
- 现场运行保留本地日志、配置快照、软件版本和设备身份；失败时先保存现场，再区分软件、网络、设备和配置问题。
