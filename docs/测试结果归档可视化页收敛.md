# 测试结果归档：可视化页报告入口收敛（步骤 8）

本文对应 [测试结果自动归档与导出流程重构计划](测试结果自动归档与导出流程重构计划.md) 的
**步骤 8：删除重复的可视化导出入口**。它接在
[历史运行/结果管理页](测试结果归档历史管理页.md)（步骤 7）之后，不重新定义归档状态，
也不改运行目录与 manifest 契约（[归档契约](测试结果归档契约.md)，步骤 2）。

本步骤完成四件事：

1. 可视化页不再自己生成报告：页面把“当前已加载结果”交给**唯一的应用层导出用例**
   （`ResultExportUseCase`），不再持有页面级报告服务；
2. 删除页面内“未加载结果就用最新结果兜底”的逻辑，报告来源只能是用户显式加载、
   带明确 `result_id` 的历史结果；
3. 视图模型同时删除 `load_latest()`：加载只经过 `load()` 或显式选择，已加载结果携带
   历史标识，可与历史行、运行逐一对应；
4. 更新用户文案与页面测试：报告自动归档、历史重试的位置改由“历史运行”页承担，
   可视化页只负责浏览与生成报告副本。

---

## 1. 入口与模块

| 模块 | 名称 | 步骤 8 的变化 |
| --- | --- | --- |
| `presentation/qt/visualization_page.py` | `VisualizationPage` | 构造参数由 `report_service` + `config_provider` 改为 `export_service`；报告动作只提交 `ExportRequest`；新增 `loaded_result_id` |
| `presentation/qt/history_view_model.py` | `HistoryViewModel`、`LoadedHistoryResult` | 删除 `load_latest()` 与 `AMPLIFIER_RESULT_TYPE`；`LoadedHistoryResult` 保留历史查询返回的 `result_id` |
| `presentation/qt/main_window.py` | `create_visualization_tab()` | 注入 `gui_data_service.export_requests`，不再把 `reports.create_summary_report` 与配置读取交给页面 |
| `tests/test_visualization_page.py` | 新增 9 项 | 报告只针对已加载结果、无隐式最新结果、导出拒绝原样转述、加载/频率浏览/失败空状态 |
| `tests/test_architecture_dependencies.py` | 新增门禁 | 可视化页必须构造 `ExportRequest` 并调用 `self.export_service.execute(`，且不得出现 `latest_result`、`load_latest`、`report_service`、`create_summary_report`、`build_report_result` |
| `tests/test_history_view_model.py` | 视图模型测试 | 删除两项 `load_latest` 用例；新增“已加载结果保留历史标识”与“视图模型没有隐式最新结果入口” |

调用形状：

```python
# 报告：页面只描述“哪一条结果、哪种格式”
outcome = export_requests.execute(
    ExportRequest(result_id=loaded.result_id, format=ExportFormat.REPORT)
)
outcome.artifact_path          # 导入用例校验后的实际报告位置

# 导出用例内部（唯一实现）
ResultExportUseCase.execute() -> 核对 result_id 在历史列表中
                              -> 只有主功放结果支持报告
                              -> ResultExportPort.export_report(result_id) -> 非空产物位置
```

## 2. 删除的重复实现

| 删除项 | 原行为 | 为什么删除 |
| --- | --- | --- |
| `VisualizationPage.report_service` | 直接调用 `ReportPort.create_summary_report(result, configuration, filename)`，用**页面当前配置**重新渲染报告 | 与导出用例 `export_report` 构成两处报告生成规则；页面还因此需要读取配置快照 |
| `VisualizationPage.config_provider` | 仅为上一条提供“当前配置” | 报告所需数据只应来自正式结果与运行 manifest，不由页面临时拼接 |
| `VisualizationPage.generate_report()` 的最新的结果兜底 | 未加载结果时调用 `history.load_latest(AMPLIFIER_RESULT_TYPE)`，把“最新的功放结果”当作报告来源 | 违反“禁止用最新文件作为隐式输入”；报告来源无法追溯到明确 `run_id` 与结果标识 |
| `HistoryViewModel.load_latest()`、`AMPLIFIER_RESULT_TYPE` | 上一条的实现，基于 `ResultQueryPort.latest_result()` | 唯一调用者已删除；保留即等于保留隐式来源 |
| 页面内的结果类型判断与“未找到测试数据文件”提示 | 页面比较 `result.is_amplifier` 并给出专用文案 | 格式适用性属于应用层导出用例（`ExportRequestError`），页面只转述原因 |
| 成功提示“测试报告已生成完成” | 不告诉用户产物在哪里 | 改为显示导出用例返回的实际产物位置 |

删除后，报告生成只剩一条应用层路径：`ResultExportUseCase` → `ResultExportPort.export_report`
（历史页“导出测试报告副本”与本页“生成报告”共用），以及自动归档侧的
`ResultArchivalService` → `ArtifactGenerator`（测试完成时写回运行目录）。两者都只在应用层
编排，Qt 页面不再出现第二份报告规则。

## 3. 保留的浏览能力与文案

- 加载：`chooser()`（基础设施的文件选择）→ `HistoryViewModel.show()` → 频率列表与绘图；
  页面不解析文档、不接触路径。
- 浏览：上一个/下一个频率的标签与按钮状态仍来自视图模型；空状态仍显示“未加载数据”
  或“数据加载失败”。
- 报告：按钮仍在，但语义收窄为“**基于当前已加载结果生成报告副本**”，并带 tooltip；
  未加载结果时提示“请先加载要生成报告的历史结果”，不再自动找最新结果。
- 页面新增一行说明文案：结果与报告在测试完成时自动归档；这里只浏览历史结果，
  “生成报告”仅针对当前已加载结果生成报告副本。
- 加载日志带上结果标识（`已加载功放测试数据: xxx.json（结果 run::<run_id>::...）`），
  用户与日志都能把图表追溯回历史行。

## 4. 仍然存在的“最新结果”入口

`presentation/qt/main_window.py::_load_cable_loss_result()` 仍通过
`ResultQueryPort.latest_result("cable_loss")` 读取最近一次线损结果供**线损页查看**。
它不参与报告生成、不进入测量输入，也不构成自动归档来源，因此不在本步骤的删除范围内；
该入口的归属调整（改为显式选择或在页面显示来源标识）留待计划步骤 10 与旧页面语义
一起收口。

## 5. 明确不属于本步骤

- 不删除 `ResultExportUseCase`、`ResultExportPort` 或归档服务中的产物生成：历史重试、
  副本导出与自动归档仍依赖它们；
- 不删除已无页面调用者的 `ReportPort` / `ReportAdapter` 与 `GuiDataService.reports`
  槽位：应用层适配器的退役属于计划步骤 10（“删除不再使用的页面专属状态和重复导出
  适配代码”），本步骤只切断页面入口，避免把结构清理混进行为收口；
- 不实现“重新生成**已成功**产物”的覆盖策略（计划步骤 9 的幂等与重试收尾）；
- 不把 `ExportPage` 类重命名为 `RunHistoryPage`、不改菜单与路由（计划步骤 10）；
- 不改变运行目录结构、manifest 校验顺序、阶段提交与取消/异常路径。

`tests/test_visualization_page.py`（9 项）覆盖：

- 报告提交 `ExportRequest(result_id=<已加载结果>, format=REPORT)`，请求不带目标路径，
  成功提示包含导出用例返回的产物位置；
- 未加载结果时拒绝生成（导出用例一次都没被调用）、未装配导出用例时拒绝、导出用例
  拒绝时原样转述原因并写日志、返回非报告结果不被当成成功；
- 加载后保留历史标识、频率列表与首频率标签；上一个/下一个频率只移动视图模型下标；
- 取消选择不改变页面状态；加载失败回到空状态并记录日志。

`tests/test_history_view_model.py` 相应变更：删除 `load_latest` 的两项用例，新增
“已加载结果保留历史标识”与“视图模型没有隐式最新结果入口”；替身查询在
`latest_result()` 上直接断言失败，防止隐式来源重新出现。

门禁：`tests/test_architecture_dependencies.py::
test_visualization_page_only_requests_reports_through_the_export_use_case` 固定“页面只提交
导出请求、不出现最新结果或页面级报告服务”；`tests/test_static_quality_gate.py` 的宽泛捕获
基线保持不变（`VisualizationPage.load_test_data#1`、`VisualizationPage.generate_report#1`
各一处，报告失败仍必须让用户看到原因）。

完整测试集：`1694` 项通过（3 项跳过）；依赖锁、启动检查与配置校验均通过。
