# 测试运行目录与配置结果解耦收尾清单

## 当前结论

核心运行目录重构、GUI 运行契约、历史只读接口及离线测试已完成；本指南对应的工作**尚未全部完成**，因此暂不删除。

剩余工作不只是最后的真实现场验收：正式测量仍写入全局兼容结果副本，历史页面仍以该目录为数据源；旧兼容测量入口和读取分支仍保留，外部调用方迁移也尚未确认。步骤 A 至 E 完成后，才能进入最后的步骤 F 现场验收。未取得现场授权前不得执行真实 RF 或电源动作。

既有完成证据及兼容接口的目标版本、迁移说明、回滚方案，分别见[兼容层弃用与删除发布说明](兼容层弃用与删除发布说明.md)和[真实 Hardware Smoke 验收记录](重构收尾与真实HardwareSmoke验收.md)。下文只追踪未完成工作，不重复已完成步骤的实现记录。

## 执行约定

- 每个子步骤单独完成、单独提交；只运行该步关联的窄范围测试，影响公共边界时再运行完整离线测试。
- 完成时勾选，并记录变更范围、实际命令和结果；若发现调用方或阻塞项，先更新发布说明和门禁测试，不得直接删除接口。
- 任何兼容层删除都必须同时满足：仓库内正式调用已迁移、外部调用方已确认迁移或退役、历史查看/回滚方案已验证。现场验收是额外的全局前置条件。

## 未完成步骤

### A. 清理旧 GUI 测量后备入口

1. **A1：移除 worker 的 `prepare_factory` 后备。** 三类 worker 缺少 `PreparedRun` 时明确失败；删除对应参数、属性和后备分支，更新 worker 单元测试。
   验收：缺少运行契约时不会调用 `prepare_configuration()`；三类 worker 的显式运行路径测试通过。
2. **A2：收紧 `prepare_configuration`。** 删除 `run_contract=False` 兼容快照分支；保留明确的创建运行、按 `run_id` 加载运行入口。先搜索仓库调用方，再更新调用和测试。
   验收：生产代码无兼容快照调用；旧参数调用明确失败或已迁出，运行配置快照测试通过。
3. **A3：删除 GUI 查询旧别名。** 删除 `ResultQueryAdapter.latest()` 和 `LegacyResultQueryPort`，历史浏览继续使用专用只读端口；同步更新公开再导出和测试。
   验收：生产及测试不再依赖旧别名，历史列表、查看和导出测试通过。
4. **A4：核实外部依赖与发布回滚。** 发布负责人登记旧 GUI 入口及查询别名的外部调用方，逐项记录迁移或退役；确认回滚版本可用后，更新[兼容层弃用与删除发布说明](兼容层弃用与删除发布说明.md)。
   验收：有可审计的外部调用方结论和回滚版本，不以“未观察到弃用告警”代替确认。

### B. 移除无路径兼容输入

1. **B1：迁移驱动映射旧分支。** 移除 `DriverPowerMappingUseCase` 的无 `stage_recorder` 最新结果读取分支；旧入口必须显式给出映射路径，或迁入运行契约。
   验收：该用例不再导入/调用 `LegacyResultInputReader`；缺路径时在硬件动作前失败。
2. **B2：迁移主功放旧分支。** 移除 `AmplifierMeasurementUseCase` 的旧无路径输入分支，要求显式映射路径或当前运行登记输入。
   验收：驱动模式缺少输入时，在连接仪器前失败；现有运行契约测量测试通过。
3. **B3：移除兼容读取器及最新路径接口。** 在 B1、B2 和 A 步骤完成且调用清单允许后，删除 `LegacyResultInputReader`、其端口/再导出，以及 `latest_path()` / `latest_compatibility_path()`；迁移相关测试。
   验收：正式与兼容生产代码均无这些接口引用；显式运行输入与历史只读查询仍通过。
4. **B4：确认旧调用方。** 按发布说明逐个确认外部脚本已迁移或退役，并记录回滚/查看路径。
   验收：外部调用方台账完成，门禁测试白名单只包含经批准的调用。

### C. 停止测量时写入全局兼容副本

1. **C1：线损用例取消兼容副本写入。** 正式运行只保存 manifest 登记的运行结果；旧兼容分支行为单独明确，不得由正式路径隐式触发。
   验收：运行结果仍可从运行目录读取；测试断言正式测量不调用 `save_compatibility_copy()`。
2. **C2：驱动映射用例取消兼容副本写入。** 独立修改并测试，不与其他测量类型合并。
   验收：当前运行结果完整，正式路径不写全局副本。
3. **C3：主功放用例取消兼容副本写入。** 独立修改并测试。
   验收：当前运行结果完整，正式路径不写全局副本。
4. **C4：移除旧仓储保存的隐式副本行为。** 检查旧入口和仓储 `save()` 调用方；改为明确的历史导入/导出操作或迁出旧入口后，再删除隐式全局副本写入。
   验收：保存运行结果不产生全局兼容副本；旧数据仍保持只读可查看。

### D. 历史浏览迁移到运行目录

1. **D1：定义 manifest 历史列表模型。** 从运行仓储读取运行及阶段结果元数据，明确缺失、损坏和部分运行的展示语义；先补端口和单元测试。
   验收：历史列表不扫描全局结果目录，运行边界校验有效。
2. **D2：实现只读运行结果加载。** 按 `run_id` 与 manifest 登记项加载、导出结果，不提供写入或任意路径访问能力。
   验收：跨运行路径、未登记文件和篡改文件均被拒绝；有效结果可读取/导出。
3. **D3：切换 GUI 历史页面。** 将列表、查看、导出逐项切换到运行历史端口；保持旧全局历史文件只读可查看，直到迁移策略获批。
   验收：新运行结果可浏览，旧历史仍可查看；UI 测试及架构依赖测试通过。
4. **D4：更新旧结果写入删除条件。** 在 C、D 完成后更新发布说明、文件清单和门禁测试，确认兼容副本停止写入不会丢失历史查看能力。
   验收：删除条件、数据保留期限、迁移说明和回滚方案均有记录。

### E. 退役旧兼容测量入口

1. **E1：盘点并确认外部入口依赖。** 覆盖 `cable_loss_measurement.py`、`driver_power_mapping.py`、主功放兼容入口及配置/结果再导出模块；逐个记录所有者、替代入口、迁移或退役结论。
   验收：无未分类外部调用方；仓库门禁清单与实际代码一致。
2. **E2：拆除线损旧入口。** 仅在外部确认及回滚版本就绪后删除或改为明确弃用失败入口，更新 release manifest 与定向测试。
   验收：新 GUI/应用入口正常；旧入口不再执行测量或写全局副本。
3. **E3：拆除驱动映射旧入口。** 单独实施、测试和更新发布清单。
   验收：运行契约输入链路正常，旧入口状态明确。
4. **E4：拆除主功放旧入口及遗留再导出。** 与 E2/E3 分开提交，按实际外部依赖决定删除或保留为有期限的弃用桩。
   验收：公开导入路径、回滚清单和兼容测试一致。
5. **E5：最终兼容层门禁复核。** 更新兼容删除条件测试和发布说明，运行全量离线测试、应用检查及配置校验。
   验收：正式流程不依赖待删兼容接口；剩余接口均有明确保留原因和责任人。

### F. 完成现场 Hardware Smoke（最后执行）

1. **F1：确认现场前置条件。** 按[真实 Hardware Smoke 验收记录](重构收尾与真实HardwareSmoke验收.md)登记授权、设备身份、正式拓扑、安全边界和动作窗口；未授权不执行。
2. **F2：执行基础连接与清理 smoke。** 归档脱敏设备身份、连接结果、异常清理和资源释放证据。
3. **F3：执行线损现场验收。** 使用新运行契约，归档正常、停止、紧急停止、异常和清理证据。
4. **F4：执行驱动映射现场验收。** 独立归档运行输入、设备拓扑、功率顺序和安全清理证据。
5. **F5：执行主功放现场验收。** 独立归档功率限制、结果、停止/异常路径和安全清理证据。
6. **F6：复核并归档。** 现场负责人确认三类完整测量及重新连接场景通过，补全验收记录和回滚决定；任何未解释失败均阻止完成标记。
