## 当前结论

核心运行目录重构、GUI 运行契约、历史只读接口及离线测试已完成；本指南对应的工作**尚未全部完成**，因此暂不删除。

剩余工作不只是最后的真实现场验收：正式测量仍写入全局兼容结果副本（步骤 C），旧兼容测量根入口仍保留（步骤 E：E1 盘点与 E5 门禁复核已完成，E2 至 E4 数据类退役阻断中）。历史浏览已在步骤 D 迁移到运行目录 manifest 视图，旧全局兼容副本保持只读可查看。步骤 C 与步骤 E 的数据类部分（E2 至 E4）须在步骤 F 归档后执行；步骤 E 的盘点（E1）、门禁复核（E5）与纯再导出模块的纯代码退役不属数据类删除，可不受步骤 F 阻断。未取得现场授权前不得执行真实 RF 或电源动作。

步骤 F 已与[真实 Hardware Smoke 验收记录](重构收尾与真实HardwareSmoke验收.md)合并：**本指南步骤 F 是现场验收的唯一操作与判定口径**，验收记录只承载脱敏现场证据、失败项、签字与回滚决定，不另立标准；两份文档出现差异时以步骤 F 为准。F 归档表示现场验收通过，**不等于**兼容层收尾完成，归档后仍须执行 C1 至 C4、E2 至 E4 并复跑门禁。

步骤 A（A1 至 A4）、步骤 B（B1 至 B4）与步骤 D（D1 至 D4）已完成并归档：旧 GUI 测量入口、无路径兼容读取器与 `latest_path()` 兼容链均已删除；外部调用方经任务授权人于 2026-10-24 确认为零调用方；B3 作为纯代码路径删除，按发布说明 6.6 的分级门槛在步骤 F 归档前获授权执行；历史列表/查看/导出已切换到运行目录历史（步骤 D），旧兼容副本仍只读可查看。证据、台账与回滚版本见[兼容层弃用与删除发布说明](兼容层弃用与删除发布说明.md)第 6、7、9 节。

既有完成证据及兼容接口的目标版本、迁移说明、回滚方案，分别见[兼容层弃用与删除发布说明](兼容层弃用与删除发布说明.md)和[真实 Hardware Smoke 验收记录](重构收尾与真实HardwareSmoke验收.md)。下文按步骤追踪状态：已完成的子步骤只保留勾选、变更范围与验证结果，未完成的子步骤保留原验收条件。

## 执行约定

- 每个子步骤单独完成、单独提交；只运行该步关联的窄范围测试，影响公共边界时再运行完整离线测试。
- 完成时勾选，并记录变更范围、实际命令和结果；若发现调用方或阻塞项，先更新发布说明和门禁测试，不得直接删除接口。
- 兼容层删除按影响面分级：
  - **数据类删除**（停止或改写入全局兼容结果、历史数据或旧运行快照，见步骤 C/D/E）必须同时满足：仓库内正式调用已迁移、外部调用方已确认迁移或退役、历史查看/回滚方案已验证，且**步骤 F 现场验收已归档**。
  - **纯代码路径删除**（不触碰任何数据文件，例如步骤 B3 的 `LegacyResultInputReader` / `latest_path()`）在同样满足“正式调用已迁移 + 外部调用方已确认 + 回滚基线已实跑验证”后执行；项目负责人于 2026-10-24 明确授权该分级（见发布说明 6.6）。在 F 归档前不得继续执行任何数据类删除。

### F. 完成现场 Hardware Smoke 验收（与现场验收记录合并，最后执行）

> **唯一验收口径**：本步骤是现场验收的唯一操作顺序与判定标准，已与[真实 Hardware Smoke 验收记录](重构收尾与真实HardwareSmoke验收.md)合并。验收记录只登记脱敏证据、失败项、签字与回滚决定；两份文档出现差异时，以本步骤为准。

> **归档不等于收尾完成**：F 归档只解除数据类删除的现场阻断，不自动完成兼容层退役。F 归档后仍须按 C1→C2→C3→C4、E2→E3→E4 的顺序完成数据类删除，再按 E5 复跑门禁与全量离线测试，才能把全部重构标记为收尾并删除本指南。
>
> **架构基线**：正式测量只写入 `runs/<run_id>/` 运行目录，结果由 manifest 登记；历史浏览走运行目录只读视图。现场验收不得回退到旧兼容测量入口、无路径“最新结果”读取或全局结果目录自动选取。基础连接与清理 smoke 不创建运行目录，不替代正式测量的运行契约。

**F1 前置条件（全部满足后才能进入 F2）**

3. DUT 保护条件、功率上限、低功率安全值、停止与紧急停止方案已确认。
4. 线损数据、功率范围、频谱仪 marker 查询和驱动功放外部供电状态已确认。

6. Hardware smoke 安全门禁：使用 `.env` 中的 `AUTO_TEST_PYTHON`、本地非示例配置、`HARDWARE_SMOKE_ENABLED=1` 和 `-ConfirmHardwareSmoke`，且不得在 CI 执行。
7. 运行契约就绪：线损、驱动映射和主功放使用已创建的 `run_id`，运行目录中的硬件配置快照校验通过，线损/驱动映射输入均由该运行 manifest 明确登记。不得从全局结果目录自动选取最新校准数据，也不得依赖旧入口或无路径读取。
8. 现场记录中的授权、设备身份、拓扑、安全边界与动作窗口已脱敏登记，现场负责人确认可以开始。
