# 测试运行目录与配置结果解耦重构指南

## 当前结论

本指南对应的核心运行目录重构已经完成，但整体计划尚未全部完成，文档暂不删除。

已完成的范围：

- 运行目录、`run_id`、`manifest.json`、相对路径和阶段状态模型已实现。
- `RunRepository` 已支持运行创建、原子 JSON 写入、文件登记、SHA-256/大小校验、完整性检查和失败清理。
- 运行创建会冻结领域配置 `config.json` 和硬件配置 `inputs/hardware_config.json`，两者独立校验并登记到 manifest。
- 线损、驱动映射和主功放的新运行路径使用当前 `run_id` 的阶段输入；缺少必需输入时在连接仪器前失败。
- 驱动模式关闭时不会要求驱动映射输入。
- 阶段结果写入当前运行目录并更新 manifest，隔离、失败、取消、篡改和部分创建场景已有测试覆盖。
- GUI 已提供“创建运行”和按 `run_id` 重新加载运行的入口，测量页面消费 `PreparedRun`，不会在开始测量前覆盖冻结配置。
- 启动器已提供列出运行、查看 manifest、校验文件和恢复前置检查的离线入口。
- 旧全局结果查询、无路径驱动映射读取和 GUI `latest()` 已进入弃用期，并发出弃用警告。

尚未完成的范围：

- 旧兼容配置、旧结果写入/查询、历史测量入口仍保留，尚未完成外部调用方迁移和删除决策。
- GUI 仍保留旧兼容快照入口；新流程已有运行契约，但尚未将所有生产入口强制收敛到运行契约。
- 真实 Hardware Smoke 和三类现场完整测量尚未完成。该事项由
  [重构收尾与真实HardwareSmoke验收.md](重构收尾与真实HardwareSmoke验收.md) 单独跟踪，未取得现场授权前不得执行真实 RF 或电源动作。

## 已完成步骤记录

原计划步骤 1 至 8 已完成，且对应模型、仓储、配置快照、阶段隔离、GUI 两阶段流程、按 `run_id` 重载和离线检查均有实现或测试。原计划步骤 9 已完成“进入弃用期”和文档约束部分，但没有完成兼容层删除，因此不标记为完成。

后续只维护未完成事项，不再重复保留已完成步骤的实施说明。

## 后续执行步骤

每个步骤应单独提交并运行对应的小范围测试。完成后在本节勾选，并记录实际验证命令和结果。

### 步骤 A：盘点新流程的生产调用方

1. 搜索生产代码中对旧配置保存、`prepare_run(..., run_contract=False)`、旧结果写入、`latest_path()`、无路径 `driver_mapping_path()` 和 GUI `latest()` 的调用。
2. 建立调用方清单，区分生产测量、历史查看、迁移工具和测试替身。
3. 不修改行为，只补充清单和对应测试位置。

验收：清单覆盖所有生产调用方；新增搜索不会发现未分类的旧接口调用。

### 步骤 B：迁移一个旧结果输入调用方

1. 选择一个生产测量入口，将其改为从当前运行的 `RunStageRecorder` 获取已登记输入。
2. 删除该入口对 `latest_path()` 或按时间查找的依赖。
3. 增加一个“当前运行缺少输入时，在硬件动作前失败”的测试。

验收：该入口在显式运行输入下不触发弃用警告，也不会读取其他运行目录的数据。

### 步骤 C：收敛 GUI 测量启动入口

1. 让线损、驱动映射和主功放页面的正式启动操作只接受带运行仓储的 `PreparedRun`。
2. 将旧兼容入口改为明确的迁移/历史查看入口，并显示不可用于正式运行的提示。
3. 增加重新打开 GUI 后按 `run_id` 启动三类测量的回归测试。

验收：正式测量页面没有无运行契约的默认路径；冻结配置被修改时，测量仍使用运行快照。

### 步骤 D：迁移历史查看和导出调用方

1. 将历史浏览改为使用专用的历史结果接口，不再复用正式测量输入接口。
2. 保留旧结果文件只读，禁止其进入新运行 manifest 之外的正式输入路径。
3. 为历史查看、迁移副本登记和正式运行输入分别补充测试。

验收：历史数据可查看/导出，但不能被“最新结果”自动带入正式运行。

### 步骤 E：确定兼容层删除条件

1. 根据步骤 A 至 D 的清单确认没有生产调用方依赖旧接口。
2. 为 `latest_path()`、无路径映射读取、旧结果写入和旧 GUI 测量入口分别写出删除条件。
3. 在发布说明中记录不兼容变更、迁移方式和目标版本。

验收：每个待删除接口都有零生产调用方证据、迁移说明和回滚/查看方案；未满足条件的接口继续保留并记录原因。

### 步骤 F：完成现场 Hardware Smoke

1. 按 [重构收尾与真实HardwareSmoke验收.md](重构收尾与真实HardwareSmoke验收.md) 取得授权、设备信息和安全窗口。
2. 依次执行基础连接与清理 smoke、线损、驱动映射和主功放现场验证。
3. 对正常、停止、紧急停止、异常和重新连接场景归档脱敏证据。

验收：现场记录满足其完成标准；真实验收完成前，不得删除本指南或现场验收文档。

## 完成判定

当步骤 A 至 E 的兼容层收敛工作完成，并且步骤 F 的现场验收文档已归档为完成时，才可以删除本指南。仅核心代码重构和离线测试完成，不足以删除本文档。
