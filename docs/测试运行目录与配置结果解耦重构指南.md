# 测试运行目录与配置结果解耦收尾清单

## 当前结论

核心运行目录重构、GUI 运行契约、历史只读接口及离线测试已完成；本指南对应的工作**尚未全部完成**，因此暂不删除。

剩余工作不只是最后的真实现场验收：正式测量仍写入全局兼容结果副本，历史页面仍以该目录为数据源；旧兼容测量根入口仍保留。步骤 C 至 E 完成后，才能进入最后的步骤 F 现场验收。未取得现场授权前不得执行真实 RF 或电源动作。

步骤 A（A1 至 A4）与步骤 B（B1 至 B4）已完成并归档：旧 GUI 测量入口、无路径兼容读取器与 `latest_path()` 兼容链均已删除；外部调用方经任务授权人于 2026-10-24 确认为零调用方；B3 作为纯代码路径删除，按发布说明 6.6 的分级门槛在步骤 F 归档前获授权执行。证据、台账与回滚版本见[兼容层弃用与删除发布说明](兼容层弃用与删除发布说明.md)第 6、7 节。

既有完成证据及兼容接口的目标版本、迁移说明、回滚方案，分别见[兼容层弃用与删除发布说明](兼容层弃用与删除发布说明.md)和[真实 Hardware Smoke 验收记录](重构收尾与真实HardwareSmoke验收.md)。下文按步骤追踪状态：已完成的子步骤只保留勾选、变更范围与验证结果，未完成的子步骤保留原验收条件。

## 执行约定

- 每个子步骤单独完成、单独提交；只运行该步关联的窄范围测试，影响公共边界时再运行完整离线测试。
- 完成时勾选，并记录变更范围、实际命令和结果；若发现调用方或阻塞项，先更新发布说明和门禁测试，不得直接删除接口。
- 兼容层删除按影响面分级：
  - **数据类删除**（停止或改写入全局兼容结果、历史数据或旧运行快照，见步骤 C/D/E）必须同时满足：仓库内正式调用已迁移、外部调用方已确认迁移或退役、历史查看/回滚方案已验证，且**步骤 F 现场验收已归档**。
  - **纯代码路径删除**（不触碰任何数据文件，例如步骤 B3 的 `LegacyResultInputReader` / `latest_path()`）在同样满足“正式调用已迁移 + 外部调用方已确认 + 回滚基线已实跑验证”后执行；项目负责人于 2026-10-24 明确授权该分级（见发布说明 6.6）。在 F 归档前不得继续执行任何数据类删除。
