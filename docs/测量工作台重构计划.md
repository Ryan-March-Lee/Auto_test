# 测量工作台重构计划

- 状态：进行中（步骤 3 完成）
- 日期：2026-11-12
- 范围：`presentation/qt` 的测量区交互与视觉；不改应用层、领域层、基础设施、测量业务和正式结果格式。

## 1. 背景与结论

当前流程分成两段，视觉语言在中间断开：

- 欢迎页、仪表配置、仪器排布、电源配置是整屏叙事：一次一个焦点，卡片代表真实对象（一台仪器、一台电源），动画承担“从上一件事到下一件事”的过渡。
- 进入工作区后变成标签页：顶部是一排匿名标签，页面用 `QGroupBox` 把“测量控制”“测量结果”分区，左侧是按钮矩阵和一块空日志，切页是瞬时替换。
- 连接成功后窗口把用户放回“测试配置”标签（`main_window.py` 的 `on_instrument_connected`），测量区的第一屏并不是测量。

**结论：不要把测量区改成前段那种全屏无卡片动画流程。**

前段是“讲故事”，测量是“开仪表”。测量的连续感应该来自一个始终不动的框架，而不是每次切页都重演一遍过场。具体做法是：

1. 用阶段条取代标签栏，把四个测量阶段和“配置”入口分开；
2. 固定外壳（阶段条、页头、左侧状态）保持不动，只让内容区做克制的过渡；
3. 测量页从“分区套卡片”改为“每页最多两块面”：控制面 + 结果面；
4. 让运行身份、当前阶段和进度在页面上持续可见；
5. 配置阶段保持 700ms 的大动画，测量阶段只用 180–240ms 的响应式动效。

## 2. 设计原则

1. **配置是叙事，测量是仪表。** 配置页可以演，测量页要稳；测量时用户需要盯数据，而不是看转场。
2. **卡片是对象，不是分区。** 一台仪器、一台电源可以是一张卡片；“测量控制”“测量结果”只是功能分区，用留白、小标题和 1px 分割线即可。
3. **连续感来自不动的框架。** 阶段条、页头、运行身份、日志位置在切页时不动，动的是它们的“内容”。
4. **两种动效语气。** 配置用 700ms 的入场/变形；测量用 180–240ms 的响应。测量进行中禁止页面过场。
5. **数据优先。** 任何动效都不能推迟数据显示、遮挡操作或让测量状态难以判断；动效只是状态变化的确认。

## 3. 目标与非目标

### 3.1 可验收目标

1. 连接成功后第一屏是“01 线损测量”，页头能看到本次 run 标识和测试模式。
2. 阶段条取代标签栏：01 线损、02 驱动映射、03 功放、04 数据可视化；“测试配置”不再占一个阶段，作为右侧“配置”入口。
3. 阶段条能表达：未开始、进行中、已完成、失败/已停止、未启用（无驱放测试）。
4. 切换测量阶段时只有内容区做 220ms 淡入 + 10px 横移；阶段条、页头、左侧状态不位移。测量进行中切页不做过渡。
5. 每个测量页最多两块面（控制面、结果面），只有一个主操作；左栏日志默认折叠为一行，仍持续接收日志。
6. 不改测量业务、请求 DTO、端口、文件格式、配置业务；不新增第三方依赖。

### 3.2 非目标

- 不把测量区做成全屏无卡片向导。
- 不做页面级大位移、遮罩、粒子、3D 或“整页翻转”。
- 不重做欢迎页、仪表配置、仪器排布、电源配置的视觉。
- 不合并三个测量页为一个控制器或一个用例。
- 不把三页合并成一个常驻测量台；该方向工作量较大，另行评估。
- 不在本计划里新增业务 KPI 计算；阶段摘要是可选增强。
- 不改变 `PageContext`、`PAGE_DEFINITIONS` 的注册职责。

## 4. 现状约束

| 约束 | 位置 | 对计划的影响 |
| --- | --- | --- |
| 页面注册唯一 | `presentation/qt/pages.py` 的 `PAGE_DEFINITIONS`、`build_pages` | 阶段条只做导航，不成为第二套页面注册表 |
| 页面生命周期 | `PageControllerBindingMixin`、`_on_page_changed`、`_sync_status_panel_visibility` | 外壳不能绕过 `on_activated` / `on_deactivated` 和状态面板挂载 |
| 页面构造门禁 | `tests/test_presentation_boundaries.py` 的页面注册与窄依赖检查 | 新控件不使用 `*Page` 命名，避免被误登记为页面 |
| QTabWidget 被大量测试依赖 | `tests/integration/test_main_window_flow.py`、`tests/ui/test_main_window.py` | 保留 `self.tab_widget` 作为内部内容宿主，只隐藏标签栏 |
| 左栏宽度唯一来源 | `theme.MEASUREMENT_LEFT_PANEL_MIN_WIDTH/MAX_WIDTH` | 三个测量页继续共用同一组宽度，不做逐页宽度 |

| 控制器状态 | `ControllerState`、`signals.state_changed` | 阶段条状态从 controller 状态派生，不复制测量状态机 |
| 测试分层 | `tools/run_tests.py --layer ui/integration` | 每个步骤按改动面选择范围，纯 UI 步骤不跑全量 |
| 无动效设置系统 | 现有动画常量散落在页面 | 新动效令牌集中到 `theme.py`，由外壳开关控制 |

## 6. 分阶段步骤

### 阶段一：基础件（4 步）

目标是先把纯数据、动效件、阶段条、外壳做成可独立测试的部件，不接主窗口。完成后不影响现有界面。

#### 步骤 1：建立测量阶段元数据

- **范围**：新增 `presentation/qt/measurement_stage.py` 和 `tests/ui/test_measurement_stage.py`。
- **工作量**：小（1 个纯 Python 模块 + 1 个测试文件）。
- **执行策略**：定义 `StageState`（`PENDING` / `ACTIVE` / `COMPLETED` / `STOPPED` / `FAILED` / `DISABLED`）、不可变 `StageDescriptor`（`key`、`order`、`title`、`subtitle`、`kind`）和 `MEASUREMENT_STAGES`；提供 `stage_for_key`、`stage_for_kind`。
- **技术决定**：
  - key 固定为 `cable_loss`、`driver_mapping`、`amplifier`、`visualization`，与 `PAGE_DEFINITIONS` 的测量项一致；用测试比对标题，避免两处文案漂移。
  - `visualization` 的 `kind` 为 `None`，不参与测量状态；无驱放测试的驱动映射阶段保留在元组里，用 `DISABLED` 表达，不删除、不重排。
  - `DISABLED` 由阶段条的 `enabled` 状态派生（无驱放测试时的驱动映射），不是运行结果；`WorkspaceRunState` 不产生该值，避免阶段条出现两个真相源。
  - 模块不导入 Qt；页面注册仍只在 `pages.py`。
- **验收**：四个阶段、顺序、标题、kind 映射正确；不依赖 Qt；与 `PAGE_DEFINITIONS` 的测量标题一致。
- **测试**：`& "D:\Anaconda\envs\Auto_test\python.exe" tools/run_tests.py --layer ui`。

#### 步骤 2：运动令牌与内容过渡件

- **范围**：`theme.py` 增加常量；新增 `presentation/qt/motion.py` 和 `tests/ui/test_motion.py`。
- **工作量**：小（1 个过渡件 + 常量）。
- **执行策略**：加入 `MOTION_REVEAL_MS = 220`、`MOTION_STAGE_MS = 180`、`MOTION_COMPLETE_MS = 260`、`MOTION_SLIDE_PX = 10`；实现 `SlideFadeEffect`（透明度 + 水平偏移的 `QGraphicsEffect`）和 `reveal(widget, direction, duration_ms)`。
- **技术决定**：
  - 只动画**进入的页面**，旧页面立即隐藏；不调用 `grab()` 做旧页快照。原因：matplotlib 页面抓图成本高，快照会让切页比现在更慢。
  - 动画结束必须 `widget.setGraphicsEffect(None)` 并删除效果对象，避免长期绘制开销；不要覆盖页面已有的 `graphicsEffect`。
  - 缓动统一 `OutCubic`，与仪器排布页的 `_TRANSITION_MS` 同一语气。
  - `duration_ms=0` 表示直接落到终态，供测试和“禁用动效”路径使用；控件不可见时同样直接落到终态（窗口首次显示、页面还没切到前台）。
  - 效果在设备坐标里用 `sourcePixmap(..., NoPad)` 取控件快照后手工合成透明度与位移，不用 `drawSource()`：控件源会绕过 painter 的透明度与变换，淡入和位移都不会落到像素上。位移按设备像素比换算；不扩展效果边界，避免移除效果后在控件矩形外留下残影。
  - 句柄在效果被页面自己的效果替换（Qt 会同步销毁效果）或控件先销毁时立即失活；收尾之后 `is_running()`/`effect()`/`animation()` 仍可安全查询。
- **验收**：效果在像素上真的淡入并位移；结束后无残留效果；`duration_ms=0` 不启动计时器；重复调用先停止上一条；中途换效果或销毁控件不抛异常。
- **测试**：`--layer ui`。

#### 步骤 3：阶段条控件

- **范围**：新增 `presentation/qt/measurement_stage_rail.py` 和 `tests/ui/test_measurement_stage_rail.py`。
- **工作量**：中（一个自绘控件 + 交互测试）。
- **执行策略**：自绘阶段条容器 + 可聚焦的阶段按钮；绘制连接线与滑动指示块；提供 `stage_selected(key)`、`set_current(key)`、`set_state(key, state)`、`set_summary(key, text)`、`set_stage_enabled(key, bool)`。
- **技术决定**：
  - 每个阶段是真实可聚焦控件，支持 Tab / Enter / Space，并设置 `accessibleName`；不要把命中区只画在画布上。
  - 指示块用 `QVariantAnimation` / `QPropertyAnimation` 移动；阶段按钮位置由布局固定，动画不改变布局。
  - 颜色、字号只取 `theme.TOKENS`；不在本模块写颜色值。
  - 未启用阶段保留可见但禁用，编号不变；没有当前阶段（配置页）时指示块隐藏，阶段条整体降低强调。
  - 阶段条是受控视图：`stage_selected` 只是导航请求，`set_current` 是唯一写入点；窗口在真正切页后再同步，拒绝/重定向导航时阶段条不能先指向别的页面。
  - `set_state` 只接受 `PENDING` / `ACTIVE` / `COMPLETED` / `STOPPED` / `FAILED` 五个运行状态；`DISABLED` 只由 `set_stage_enabled` 派生，不能成为第二真相源。
  - `visualization`（`kind is None`）是只读视图：不画运行状态标记，不接受 `set_state`，无障碍描述用“只读视图，不参与测量状态”；它仍可作为当前阶段导航。
  - 无当前阶段的降低强调用文字/徽章令牌完成，不对可交互按钮整体压透明度；悬停用中性浅底 + 描边，和浅主色的当前指示块区分。
  - 停用当前阶段不自动导航；窗口负责切页并同步 `current`，阶段条只如实显示当前阶段与停用状态。
- **验收**：点击只发出 key、不写 current；禁用阶段不可点；键盘可切换；状态、摘要、当前项可独立更新；`DISABLED` 与只读阶段不能写入状态；无当前阶段的标题仍可读；当前阶段无障碍描述可辨；窗口缩放不跳位。
- **测试**：`--layer ui`。

#### 步骤 4：测量工作台外壳

- **范围**：新增 `presentation/qt/measurement_workspace.py` 和 `tests/ui/test_measurement_workspace.py`。
- **工作量**：中（组合现有阶段条与页头，不接业务）。
- **执行策略**：组合阶段条、页头（eyebrow / 标题 / 副标题 / 右侧状态区）和内容槽；公开 `set_content(widget)`、`add_right_widget(widget)`、`set_current_stage(key)`、`show_utility(title, subtitle)`、`set_run_identity(run_id, mode_text)`、`set_stage_state(...)`、`set_animations_enabled(bool)`；发出 `stage_selected`、`configuration_requested`。
- **技术决定**：
  - 外壳**不拥有**内容栈、不导入页面类、不调用页面生命周期；内容由主窗口通过 `set_content` 注入。第一阶段继续由 `QTabWidget` 承载页面。
  - 页头只做展示，不读配置、不读运行服务；`run_id`、模式文本由窗口传入。
  - 类名不使用 `Page` 后缀，避免触发页面注册门禁。
  - 内容槽只接受一个 widget；替换时从布局移除旧 widget，不销毁它。
- **验收**：能独立构造并展示阶段条/页头/占位内容；`show_utility` 不点亮任何阶段；`set_content` 不改变页面所有权。
- **测试**：`--layer ui`；不触发 `test_presentation_boundaries` 的新页面登记。

### 阶段二：接入主窗口（4 步）

目标是让新外壳接管现有标签页的外观与导航，但保留页面、状态面板和测量逻辑不动。完成阶段二即可得到一个可运行、可回退的版本。

#### 步骤 5：用工作台外壳包住现有标签内容

- **范围**：`main_window.py`，必要时补 `tests/ui/test_main_window.py` 与新增 `tests/ui/test_measurement_workspace_wiring.py`。
- **工作量**：中（窗口装配一处，但影响集成测试）。
- **执行策略**：
  - 在 `init_ui` 创建 `MeasurementWorkspace(MEASUREMENT_STAGES)`，把 `self.tab_widget` 放进外壳内容槽；调用 `self.tab_widget.tabBar().hide()`，不再显示标签栏。
  - 删除 `tab_widget.setCornerWidget(...)`；把现有 `self.mode_badge` 通过 `add_right_widget()` 挂到外壳右侧状态区。
  - 连接 `workspace.stage_selected` → 选中对应页面；`tab_widget.currentChanged` 继续走 `_on_page_changed`，并在末尾同步外壳的页头/阶段条。
  - 配置页没有阶段 key：`_sync_workspace` 检测到 `test_config_page` 时调用 `show_utility("测试配置", ...)`。
- **技术决定**：
  - **保留 `QTabWidget` 作为内部内容宿主**，不替换成 `QStackedWidget`。原因：页面注册、`currentChanged`、状态面板挂载与大量集成测试都依赖它；隐藏标签栏只是外观变化，回退成本最低。
  - 保留 `self.tab_widget` 与 `self.pages` 的公开形状；`PAGE_DEFINITIONS`、`build_pages`、`PageContext` 不动。
  - 驱动映射页仍按现有逻辑 `setTabVisible(False)`；阶段条对应项用 `DISABLED`，不重排编号。
  - 主窗口仍是唯一装配根；外壳不导入任何页面类型。
- **验收**：现有页面数量、标题、`tabText`、`isTabVisible` 行为不变；阶段条点击能切页；标签切换能反向更新阶段条和页头；配置页显示“测试配置”页头且不点亮阶段；状态面板仍挂到当前测量页。
- **测试**：`tools/run_tests.py --layer integration`（真实窗口 + UI 层）；`test_architecture_dependencies` 仍应看到 `self.tab_widget.addTab(...)`。

#### 步骤 6：页头运行身份与“配置”入口

- **范围**：`measurement_workspace.py`、`main_window.py`，补 UI/集成测试。
- **工作量**：小（页头展示 + 一个回调）。
- **执行策略**：
  - 新增 `_sync_workspace_identity()`：从 `coordinator.current_run_id()` 取 run id，从 `coordinator.amplifier_driver_mode()` 取模式文本，写入外壳；无运行时显示“未连接”。
  - 在外壳右侧增加“配置”文字动作，发出 `configuration_requested`，窗口调用现有 `_open_workspace_configuration()` 回到配置页。
  - 在 `on_instrument_connected`、`load_prepared_run`、`_sync_finalize_entry` 后刷新身份。
- **技术决定**：
  - run id 与模式只做展示，不新增 `PageContext` 字段、不新增应用服务。
  - 配置入口是工具动作，不是第五个阶段；阶段编号保持 01–04。
  - 本步不显示“依赖就绪/6 频点”等阶段摘要，等步骤 8 和可选步骤 15 再补，避免先放假数据。
- **验收**：连接后页头显示 run id 与模式；点击“配置”回到配置页；无运行时显示“未连接”；不改变测量启动/连接流程。
- **测试**：`--layer ui` + `--layer integration`。

#### 步骤 7：连接成功后的交接

- **范围**：`main_window.on_instrument_connected`，补集成测试。
- **工作量**：小（一个入口 + 断言更新）。
- **执行策略**：连接提交成功后，不再 `setCurrentIndex(0)`；若当前页仍是测试配置页，则切到 `cable_loss` 并写一条“已进入线损测量”日志。重连或恢复时如果用户已经在测量页，不强行拉回。
- **技术决定**：
  - 只做“配置 → 第一个测量阶段”的一次性交接，不自动开始测量。
  - 不自动跳到驱动映射或功放；后续阶段由用户点击阶段条进入。
  - 本步不做动画，动画统一在步骤 13 接入。
- **验收**：模拟连接成功后当前页是线损页，阶段条 01 为当前；配置入口仍可回配置页；重连不打断当前测量页。
- **测试**：`--layer integration`；更新现有“连接后仍在配置页”的断言。

#### 步骤 8：阶段状态模型与接线

- **范围**：新增 `presentation/qt/workspace_state.py`、`tests/ui/test_workspace_state.py`；`main_window.py` 接线。
- **工作量**：中（纯模型 + 一条信号接线）。
- **执行策略**：
  - `WorkspaceRunState` 记录当前 run 下每个阶段的 `StageState`：`observe(ControllerState)` 把 `MeasurementKind` 映射到阶段 key；终态保留到 run 重置。
  - 窗口连接 `measurement_controller.signals.state_changed`，把状态推给外壳；run id 变化复用步骤 6 的同步入口，发现新 id 时 `reset_run(run_id)`。
  - 取消/停止显示为“已停止”（警告色），失败显示“失败”，完成显示“完成”。
- **技术决定**：
  - 状态模型是纯 Python，不导入 Qt，不复制 `MeasurementLifecycle`；它只消费 `ControllerState` 的 `kind`/`status`。
  - 不解析结果 DTO、不统计频点数；摘要延后到可选步骤 15。
  - 控制器下一次启动会用新状态覆盖自身快照，因此“上一个阶段已完成”必须由工作台模型记住，不能从 controller 当前状态推断。
  - `visualization` 不参与状态；`test_configuration` 不进入模型。
- **验收**：进行中显示 ACTIVE；完成保留 COMPLETED；失败/停止对应红色/警告；换 run 重置；切页不改变阶段状态。
- **测试**：`--layer ui`（纯模型 + 外壳）+ `--layer integration`（真实信号接线）。

### 阶段四：动效与收束（2 步）

#### 步骤 13：阶段切换动效

- **范围**：`main_window.py`、`measurement_workspace.py`、`motion.py`，补 UI/集成测试。
- **工作量**：中（接线 + 门禁 + 实机检查）。
- **执行策略**：
  - 在标签页切换完成后，对当前页调用 `reveal()`；方向由阶段顺序决定，向右切页从右向左轻移，向左切页反之。
  - 只对测量/可视化阶段生效；配置页、首次显示、测量进行中不播放。
- **技术决定**：
  - 只动画进入页；旧页立即隐藏，避免 `grab()` 开销和双页重绘。
  - 同一时刻最多一个过渡；新切换开始前停止旧的并清理效果。
  - 测量进行中（`controller.state.is_active`）一律瞬时切换，保证监控不被动画推迟。
  - 提供 `animations_enabled` 开关；测试与排障可关闭，不引入环境变量或设置页。
  - 如果实机发现 matplotlib 页面在效果下明显掉帧，退化为“只淡入不位移”或“只动结果面”，不改业务结构。
- **验收**：切页有 220ms 淡入 + 10px 位移；阶段条/页头/左栏不动；测量中切页瞬时；动画结束无残留效果。
- **测试**：`--layer ui` + `--layer integration`；手动离屏/真机各看一次切页。

#### 步骤 14：运行中的微动效与完成收束

- **范围**：`measurement_workspace.py`、`measurement_stage_rail.py`、`main_window.py`，补 UI 测试。
- **工作量**：小到中（状态动效，集中在一个共享动画）。
- **执行策略**：
  - 页头下方增加 2px 进度发丝线，连接 `signals.progress`；只在有活动测量时显示，空闲隐藏。
  - 阶段条的 ACTIVE 项加一个呼吸点，COMPLETED 项落绿并做一次 260ms 扫过；FAILED 项保持红色，不闪。
  - 动画在测量结束、切到配置页或窗口关闭时停止。
- **技术决定**：
  - 发丝线是状态指示，不替代状态面板里的详细进度条，也不新增数值来源。
  - 用一个共享的 `QPropertyAnimation` 驱动呼吸点，不为每个阶段各起一个计时器；空闲时停止，避免后台 CPU。
  - 不做结果表逐行 stagger：`QTableWidget` 行级动画成本高、收益低；结果面整体一次淡入已经足够。
  - 完成态只在状态从 ACTIVE 变为 COMPLETED 时播放一次；重复进入页面不重播。
- **验收**：进度只在活动时出现；完成/失败状态清晰；空闲无动画计时器；关闭窗口无泄漏。
- **测试**：`--layer ui`。

### 阶段五：可选增强（不阻塞主线）

#### 步骤 15（可选）：阶段摘要与结果 KPI

- **范围**：三个测量页各加一个窄方法（如 `stage_summary()` / `stage_metrics()`），工作台页头和阶段条消费。
- **工作量**：中（三页各一处取数 + 排版）。
- **执行策略**：页面从自己已经显示的数据里返回“频点数/当前频点/最近更新时间”或四项 KPI；工作台只负责排版，不做计算。
- **技术决定**：摘要必须来自页面现有数据，不新增业务查询；没有数据时显示“未开始”，不显示 0 或假值。完成后阶段条可显示“6 频点”，结果面可显示 KPI 行。
- **验收**：摘要与实际表格/曲线一致；空态不误导；不影响测量启动。

**不列入本计划、另行评估**：把三个测量页合并成一个常驻测量台（外壳拥有左栏和控制面，右侧只替换结果面，`StatusPanel` 不再在页面间 `unmount/mount`）。它的收益是彻底消除切页时的左栏重挂，但会改变页面构造与测试边界，工作量明显大于前 14 步；只有前 14 步落地后仍觉得左栏闪烁，或产品明确要求“一个控制台”时，再单独立项。

## 7. 测试与交付策略

| 阶段 | 命令 | 说明 |
| --- | --- | --- |
| 步骤 1–4 | `tools/run_tests.py --layer ui` | 纯表现层新件，不接主窗口 |
| 步骤 5–8 | `tools/run_tests.py --layer integration` | 真实窗口接线；包含 UI 层与仓库门禁 |
| 步骤 9–12 | `tools/run_tests.py --layer ui` | 纯页面视觉，不改 DTO/端口 |
| 步骤 13–14 | `--layer ui` + `--layer integration` | 动效需真实窗口验证 |
| 交付前 | 全量离线测试 + `launcher.py --check` + `launcher.py --validate-config` | 按项目规则收尾 |

每个阶段结束都是可暂停点：

- 阶段二结束：已有阶段条、页头、连接后交接，测量逻辑未动，可以先交付。
- 阶段三结束：视觉统一，仍无新动效。
- 阶段四结束：动效完成，主线结束。

门禁关注点：

- 新类不使用 `*Page` 命名；若未来确实新增页面类，必须登记 `REGISTERED_PAGE_MODULES` 并更新页面构造门禁。
- 保持 `self.tab_widget.addTab(page, definition.title)` 与 `self.pages` 形状，避免 `tests/test_architecture_dependencies.py` 和大量集成用例无谓改写。
- 保持 `MEASUREMENT_LEFT_PANEL_*` 为唯一宽度来源。
- 新模块不导入 `app`/`infrastructure`/硬件；外壳不导入页面类型。
- 不新增宽泛 `except Exception: pass`；新失败路径走日志或既有错误通道。

## 8. 风险与回退

| 风险 | 表现 | 应对 |
| --- | --- | --- |
| 隐藏 `QTabBar` 丢失键盘导航 | 只能用鼠标切页 | 阶段条阶段项可聚焦，支持 Tab/Enter/Space；补键盘测试 |
| `QGraphicsEffect` 拖慢 matplotlib | 切页掉帧、曲线重绘 | 只动画进入页、220ms、结束即移除；必要时退化为淡入或只动结果面 |
| 状态面板重挂闪烁 | 切页时左栏日志闪一下 | 前 14 步只动内容区；若仍明显，提前评估“常驻测量台”方向 |
| 页面结构改动导致测试大面积失败 | 公开属性/信号被改名 | 所有公开控件名与信号保持不变，只改容器与排版 |
| 连接后自动跳转打断用户 | 重连时被拉回线损页 | 只在当前是配置页时交接；重连/已在本页不跳 |
| 动效在测量中干扰监控 | 切页延迟、状态看不清 | 测量活动时禁用过渡；动效不遮挡数据 |
| 阶段条与 `PAGE_DEFINITIONS` 文案漂移 | 两处标题不一致 | 步骤 1 的测试比对；标题改动必须同步两处 |

回退策略：

- 阶段二的外壳可以整体回退为“显示标签栏、移除外壳”，页面与业务不动。
- 阶段三的每个页面独立改，可单页回退。
- 阶段四通过 `animations_enabled=False` 一键关闭，不影响布局与业务。

## 9. 完成定义

- 连接成功后第一屏是线损测量，页头有 run id 与测试模式。
- 阶段条稳定显示四个阶段，完成/进行中/失败/未启用可辨；配置入口独立。
- 切页只动内容区，220ms 淡入 + 10px 横移；测量进行中瞬时切换。
- 三个测量页结构一致：控制面 + 结果面，每页一个主操作；日志默认折叠且不丢消息。
- 左栏宽度、页面注册、`PageContext`、测量 DTO/端口/文件格式均未改变。
- 对应测试范围通过；交付前全量测试与 `launcher.py` 检查通过。
