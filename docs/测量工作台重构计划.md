# 测量工作台重构计划

- 状态：已完成（主线 14 步 + 可选步骤 15 全部落地）
- 日期：2026-11-13
- 范围：`presentation/qt` 的测量区交互与视觉；不改应用层、领域层、基础设施、测量业务和正式结果格式。

## 1. 背景与结论

当前流程分成两段，视觉语言在中间断开：

- 欢迎页、仪表配置、仪器排布、电源配置是整屏叙事：一次一个焦点，卡片代表真实对象（一台仪器、一台电源），动画承担“从上一件事到下一件事”的过渡。
- 进入工作区后变成标签页：顶部是一排匿名标签，页面用 `QGroupBox` 把“测量控制”“测量结果”分区，左侧是按钮矩阵和一块空日志，切页是瞬时替换。
- 连接成功后窗口把用户放回“测试配置”标签（`main_window.py` 的 `on_instrument_connected`），测量区的第一屏并不是测量。

**结论：不要把测量区改成前段那种全屏无卡片动画流程。**

前段是“讲故事”，测量是“开仪表”。测量的连续感应该来自一个始终不动的框架，而不是每次切页都重演一遍过场。具体做法是：

1. 用阶段条取代标签栏，把四个测量阶段和“配置”入口分开；
2. 固定外壳（阶段条、页头、左侧状态）保持不动，只让内容区做克制的过渡；
3. 测量页从“分区套卡片”改为“每页最多两块面”：控制面 + 结果面；
4. 让运行身份、当前阶段和进度在页面上持续可见；
5. 配置阶段保持 700ms 的大动画，测量阶段只用 180–240ms 的响应式动效。

## 2. 设计原则

1. **配置是叙事，测量是仪表。** 配置页可以演，测量页要稳；测量时用户需要盯数据，而不是看转场。
2. **卡片是对象，不是分区。** 一台仪器、一台电源可以是一张卡片；“测量控制”“测量结果”只是功能分区，用留白、小标题和 1px 分割线即可。
3. **连续感来自不动的框架。** 阶段条、页头、运行身份、日志位置在切页时不动，动的是它们的“内容”。
4. **两种动效语气。** 配置用 700ms 的入场/变形；测量用 180–240ms 的响应。测量进行中禁止页面过场。
5. **数据优先。** 任何动效都不能推迟数据显示、遮挡操作或让测量状态难以判断；动效只是状态变化的确认。

## 3. 目标与非目标

### 3.1 可验收目标

1. 连接成功后第一屏是“01 线损测量”，页头能看到本次 run 标识和测试模式。
2. 阶段条取代标签栏：01 线损、02 驱动映射、03 功放、04 数据可视化；“测试配置”不再占一个阶段，作为右侧“配置”入口。
3. 阶段条能表达：未开始、进行中、已完成、失败/已停止、未启用（无驱放测试）。
4. 切换测量阶段时只有内容区做 220ms 淡入 + 10px 横移；阶段条、页头、左侧状态不位移。测量进行中切页不做过渡。
5. 每个测量页最多两块面（控制面、结果面），只有一个主操作；左栏日志默认折叠为一行，仍持续接收日志。
6. 不改测量业务、请求 DTO、端口、文件格式、配置业务；不新增第三方依赖。

### 3.2 非目标

- 不把测量区做成全屏无卡片向导。
- 不做页面级大位移、遮罩、粒子、3D 或“整页翻转”。
- 不重做欢迎页、仪表配置、仪器排布、电源配置的视觉。
- 不合并三个测量页为一个控制器或一个用例。
- 不把三页合并成一个常驻测量台；该方向工作量较大，另行评估。
- 不在本计划里新增业务 KPI 计算；阶段摘要是可选增强。
- 不改变 `PageContext`、`PAGE_DEFINITIONS` 的注册职责。

## 4. 现状约束

| 约束 | 位置 | 对计划的影响 |
| --- | --- | --- |
| 页面注册唯一 | `presentation/qt/pages.py` 的 `PAGE_DEFINITIONS`、`build_pages` | 阶段条只做导航，不成为第二套页面注册表 |
| 页面生命周期 | `PageControllerBindingMixin`、`_on_page_changed`、`_sync_status_panel_visibility` | 外壳不能绕过 `on_activated` / `on_deactivated` 和状态面板挂载 |
| 页面构造门禁 | `tests/test_presentation_boundaries.py` 的页面注册与窄依赖检查 | 新控件不使用 `*Page` 命名，避免被误登记为页面 |
| QTabWidget 被大量测试依赖 | `tests/integration/test_main_window_flow.py`、`tests/ui/test_main_window.py` | 保留 `self.tab_widget` 作为内部内容宿主，只隐藏标签栏 |
| 左栏宽度唯一来源 | `theme.MEASUREMENT_LEFT_PANEL_MIN_WIDTH/MAX_WIDTH` | 三个测量页继续共用同一组宽度，不做逐页宽度 |
| 状态面板唯一 | `StatusPanel` 全局复用，切页时 `unmount/mount` | 第一阶段不动所有权；动画只作用于内容区，避免面板重挂闪烁 |
| 控制器状态 | `ControllerState`、`signals.state_changed` | 阶段条状态从 controller 状态派生，不复制测量状态机 |
| 测试分层 | `tools/run_tests.py --layer ui/integration` | 每个步骤按改动面选择范围，纯 UI 步骤不跑全量 |
| 无动效设置系统 | 现有动画常量散落在页面 | 新动效令牌集中到 `theme.py`，由外壳开关控制 |

## 5. 目标形态

```text
┌──────────────────────────────────────────────────────────────┐
│ 01 线损 ✓  02 驱动映射 ✓  03 功放 ●  04 可视化 │ 本次运行… [模式] [配置] │  ← 顶栏（常驻）
├───────────────────────┬──────────────────────────────────────┤
│ 控制面                │ 结果面                               │
│ 当前频点 / 进度        │ 标题 / 频点导航 / KPI / 图表或表格    │  ← 内容区（切换时动）
│ 主操作 / 次操作        │                                      │
│ 校准输入 / 日志一行    │                                      │
└───────────────────────┴──────────────────────────────────────┘
```

页头不再是独立一行：运行标识、模式徽标与“配置”入口在阶段条右侧，阶段摘要只在
阶段按钮上展示（2026-11 布局调整，见第 10 节）。

阶段定义：

| 序号 | key | 标题 | 类型 | 说明 |
| --- | --- | --- | --- | --- |
| 01 | `cable_loss` | 线损测量 | 测量 | 首个测量阶段 |
| 02 | `driver_mapping` | 驱动映射 | 测量 | 无驱放测试时显示为“未启用”，不重新编号 |
| 03 | `amplifier` | 功放测试 | 测量 | 主测量阶段 |
| 04 | `visualization` | 数据可视化 | 查看 | 只读，不参与完成态 |

`test_configuration` 不属于阶段条，作为右侧“配置”入口；进入时阶段条置为无当前阶段，页头不重复显示工具页标题。

动效规范：

| 场景 | 时长 | 缓动 | 位移 | 禁用条件 |
| --- | --- | --- | --- | --- |
| 测量阶段切换 | 220ms | `OutCubic` | 内容区 10px 横移 + 淡入 | 测量进行中；从/到配置页；窗口首次显示 |
| 阶段条指示器移动 | 180ms | `OutCubic` | 指示块跟随 | 无 |
| 阶段进行中呼吸 | 1600ms 循环 | 线性 | 光晕透明度 + 半径 | 没有 ACTIVE 项；没有当前阶段；阶段条不可见；关闭动效 |
| 阶段完成落绿 | 260ms | `OutCubic` | 一次性扫过 | 非 ACTIVE → COMPLETED；目标被停用或写离完成态；没有当前阶段 |
| 运行进度发丝线 | 跟随进度信号 | 线性映射（不插值） | 宽度 | 空闲时隐藏 |
| 整屏配置步骤 | 保持不变 | 现有 700ms 动画 | 现有卡片变形 | 不属于本计划 |

## 6. 分阶段步骤

### 阶段一：基础件（4 步）

目标是先把纯数据、动效件、阶段条、外壳做成可独立测试的部件，不接主窗口。完成后不影响现有界面。

#### 步骤 1：建立测量阶段元数据

- **范围**：新增 `presentation/qt/measurement_stage.py` 和 `tests/ui/test_measurement_stage.py`。
- **工作量**：小（1 个纯 Python 模块 + 1 个测试文件）。
- **执行策略**：定义 `StageState`（`PENDING` / `ACTIVE` / `COMPLETED` / `STOPPED` / `FAILED` / `DISABLED`）、不可变 `StageDescriptor`（`key`、`order`、`title`、`subtitle`、`kind`）和 `MEASUREMENT_STAGES`；提供 `stage_for_key`、`stage_for_kind`。
- **技术决定**：
  - key 固定为 `cable_loss`、`driver_mapping`、`amplifier`、`visualization`，与 `PAGE_DEFINITIONS` 的测量项一致；用测试比对标题，避免两处文案漂移。
  - `visualization` 的 `kind` 为 `None`，不参与测量状态；无驱放测试的驱动映射阶段保留在元组里，用 `DISABLED` 表达，不删除、不重排。
  - `DISABLED` 由阶段条的 `enabled` 状态派生（无驱放测试时的驱动映射），不是运行结果；`WorkspaceRunState` 不产生该值，避免阶段条出现两个真相源。
  - 模块不导入 Qt；页面注册仍只在 `pages.py`。
- **验收**：四个阶段、顺序、标题、kind 映射正确；不依赖 Qt；与 `PAGE_DEFINITIONS` 的测量标题一致。
- **测试**：`& "D:\Anaconda\envs\Auto_test\python.exe" tools/run_tests.py --layer ui`。

#### 步骤 2：运动令牌与内容过渡件

- **范围**：`theme.py` 增加常量；新增 `presentation/qt/motion.py` 和 `tests/ui/test_motion.py`。
- **工作量**：小（1 个过渡件 + 常量）。
- **执行策略**：加入 `MOTION_REVEAL_MS = 220`、`MOTION_STAGE_MS = 180`、`MOTION_COMPLETE_MS = 260`、`MOTION_SLIDE_PX = 10`；实现 `SlideFadeEffect`（透明度 + 水平偏移的 `QGraphicsEffect`）和 `reveal(widget, direction, duration_ms)`。
- **技术决定**：
  - 只动画**进入的页面**，旧页面立即隐藏；不调用 `grab()` 做旧页快照。原因：matplotlib 页面抓图成本高，快照会让切页比现在更慢。
  - 动画结束必须 `widget.setGraphicsEffect(None)` 并删除效果对象，避免长期绘制开销；不要覆盖页面已有的 `graphicsEffect`。
  - 缓动统一 `OutCubic`，与仪器排布页的 `_TRANSITION_MS` 同一语气。
  - `duration_ms=0` 表示直接落到终态，供测试和“禁用动效”路径使用；控件不可见时同样直接落到终态（窗口首次显示、页面还没切到前台）。
  - 效果在设备坐标里用 `sourcePixmap(..., NoPad)` 取控件快照后手工合成透明度与位移，不用 `drawSource()`：控件源会绕过 painter 的透明度与变换，淡入和位移都不会落到像素上。位移按设备像素比换算；不扩展效果边界，避免移除效果后在控件矩形外留下残影。
  - 句柄在效果被页面自己的效果替换（Qt 会同步销毁效果）或控件先销毁时立即失活；收尾之后 `is_running()`/`effect()`/`animation()` 仍可安全查询。
- **验收**：效果在像素上真的淡入并位移；结束后无残留效果；`duration_ms=0` 不启动计时器；重复调用先停止上一条；中途换效果或销毁控件不抛异常。
- **测试**：`--layer ui`。

#### 步骤 3：阶段条控件

- **范围**：新增 `presentation/qt/measurement_stage_rail.py` 和 `tests/ui/test_measurement_stage_rail.py`。
- **工作量**：中（一个自绘控件 + 交互测试）。
- **执行策略**：自绘阶段条容器 + 可聚焦的阶段按钮；绘制连接线与滑动指示块；提供 `stage_selected(key)`、`set_current(key)`、`set_state(key, state)`、`set_summary(key, text)`、`set_stage_enabled(key, bool)`。
- **技术决定**：
  - 每个阶段是真实可聚焦控件，支持 Tab / Enter / Space，并设置 `accessibleName`；不要把命中区只画在画布上。
  - 指示块用 `QVariantAnimation` / `QPropertyAnimation` 移动；阶段按钮位置由布局固定，动画不改变布局。
  - 颜色、字号只取 `theme.TOKENS`；不在本模块写颜色值。
  - 未启用阶段保留可见但禁用，编号不变；没有当前阶段（配置页）时指示块隐藏，阶段条整体降低强调。
  - 阶段条是受控视图：`stage_selected` 只是导航请求，`set_current` 是唯一写入点；窗口在真正切页后再同步，拒绝/重定向导航时阶段条不能先指向别的页面。
  - `set_state` 只接受 `PENDING` / `ACTIVE` / `COMPLETED` / `STOPPED` / `FAILED` 五个运行状态；`DISABLED` 只由 `set_stage_enabled` 派生，不能成为第二真相源。
  - `visualization`（`kind is None`）是只读视图：不画运行状态标记，不接受 `set_state`，无障碍描述用“只读视图，不参与测量状态”；它仍可作为当前阶段导航。
  - 无当前阶段的降低强调用文字/徽章令牌完成，不对可交互按钮整体压透明度；悬停用中性浅底 + 描边，和浅主色的当前指示块区分。
  - 停用当前阶段不自动导航；窗口负责切页并同步 `current`，阶段条只如实显示当前阶段与停用状态。
- **验收**：点击只发出 key、不写 current；禁用阶段不可点；键盘可切换；状态、摘要、当前项可独立更新；`DISABLED` 与只读阶段不能写入状态；无当前阶段的标题仍可读；当前阶段无障碍描述可辨；窗口缩放不跳位。
- **测试**：`--layer ui`。

#### 步骤 4：测量工作台外壳

- **范围**：新增 `presentation/qt/measurement_workspace.py` 和 `tests/ui/test_measurement_workspace.py`。
- **工作量**：中（组合现有阶段条与页头，不接业务）。
- **执行策略**：组合阶段条、页头（右侧运行身份 / 摘要 / 配置入口）和内容槽；公开 `set_content(widget)`、`add_right_widget(widget)`、`set_current_stage(key)`、`show_utility()`、`set_run_identity(run_id, mode_label)`、`set_stage_state(...)`、`set_animations_enabled(bool)`；发出 `stage_selected`、`configuration_requested`。
- **技术决定**：
  - 外壳**不拥有**内容栈、不导入页面类、不调用页面生命周期；内容由主窗口通过 `set_content` 注入。第一阶段继续由 `QTabWidget` 承载页面。
  - 页头只做展示，不读配置、不读运行服务；`run_id`、模式文本由窗口传入。
  - 类名不使用 `Page` 后缀，避免触发页面注册门禁。
  - 内容槽只接受一个 widget；替换时从布局移除旧 widget，不销毁它。
  - 当前阶段只在构造时传入的阶段集合里查找，不回落到全局 `MEASUREMENT_STAGES`；否则自定义阶段会出现“画得出、同步不了”的半成品状态。
  - `set_content` / `add_right_widget` 拒绝外壳自己的结构控件（阶段条、页头、内容宿主及其子控件）和外壳的祖先；拒绝时不改动已有内容，常驻框架不能被自己的接口拆开。
- **验收**：能独立构造并展示阶段条/页头/占位内容；`show_utility` 不点亮任何阶段；`set_content` 不改变页面所有权。
- **测试**：`--layer ui`；不触发 `test_presentation_boundaries` 的新页面登记。

### 阶段二：接入主窗口（4 步）

目标是让新外壳接管现有标签页的外观与导航，但保留页面、状态面板和测量逻辑不动。完成阶段二即可得到一个可运行、可回退的版本。

#### 步骤 5：用工作台外壳包住现有标签内容

- **范围**：`main_window.py`、新增 `presentation/qt/workspace_binding.py`；测试为新增 `tests/ui/test_workspace_binding.py`、`tests/ui/test_measurement_workspace.py` 与 `tests/integration/test_main_window_flow.py`。
- **工作量**：中（窗口装配一处 + 一个同步绑定，但影响集成测试）。
- **执行策略**：
  - 在 `init_ui` 创建 `MeasurementWorkspace(MEASUREMENT_STAGES)`，把 `self.tab_widget` 放进外壳内容槽；调用 `self.tab_widget.tabBar().hide()`，不再显示标签栏。
  - 删除 `tab_widget.setCornerWidget(...)`；把现有 `self.mode_badge` 通过 `add_right_widget()` 挂到外壳右侧状态区。
  - 新增 `WorkspaceBinding(workspace, tab_widget, pages)`：`stage_selected` → `binding.navigate(key)`；`currentChanged` 继续走 `_on_page_changed`，末尾调用 `binding.sync()`；驱动模式切换走 `binding.set_stage_enabled("driver_mapping", enabled)`。
  - 配置页等非阶段页：binding 用 `workspace.has_stage(key)` 分流，非阶段页只调用 `show_utility()`，页头不重复写工具页标题；工具页上禁用“配置”动作，离开后恢复。
  - 恢复 `tabBar().setDrawBase(False)` 再隐藏，保留“显示标签栏”的回退路径。
- **技术决定**：
  - **保留 `QTabWidget` 作为内部内容宿主**，不替换成 `QStackedWidget`。原因：页面注册、`currentChanged`、状态面板挂载与大量集成测试都依赖它；隐藏标签栏只是外观变化，回退成本最低。
  - **同步收敛到 `WorkspaceBinding`**：不导入 Qt（仅类型检查引用 `QTabWidget`）、不导入页面类；两个同步入口都是信号槽，未知 key、不可见标签页、未登记 widget 一律静默忽略，不能抛异常打断信号分发。
  - **“是不是阶段”由外壳回答**（`has_stage`），窗口不再硬编码“当前是不是配置页”。新增报告/历史这类非阶段页只登记 `PAGE_DEFINITIONS`，窗口与 binding 都不用改，也不会再出现“画得出、同步不了”的 `KeyError`。
  - 保留 `self.tab_widget` 与 `self.pages` 的公开形状；`PAGE_DEFINITIONS`、`build_pages`、`PageContext` 不动。
  - 驱动映射页仍按现有逻辑 `setTabVisible(False)`；阶段条对应项用 `DISABLED`，不重排编号。
  - 主窗口仍是唯一装配根；外壳不导入任何页面类型。

#### 步骤 13：阶段切换动效

- **范围**：`main_window.py`、`measurement_workspace.py`、`motion.py`，补 UI/集成测试。

- **技术决定**：
  - 只动画进入页；旧页立即隐藏，避免 `grab()` 开销和双页重绘。
  - 同一时刻最多一个过渡；新切换开始前停止旧的并清理效果。
  - 测量进行中（`controller.state.is_active`）一律瞬时切换，保证监控不被动画推迟。
  - 提供 `animations_enabled` 开关；测试与排障可关闭，不引入环境变量或设置页。
  - 如果实机发现 matplotlib 页面在效果下明显掉帧，退化为“只淡入不位移”或“只动结果面”，不改业务结构。
- **已落地决定**：进入方向由 `MeasurementWorkspace.stage_reveal_direction()` 按阶段顺序回答（序号增大从右轻移、减小从左轻移；任一端不是阶段就完全不播放）；过渡由同一模块的 `reveal_current_page()` 在内容槽的“当前页”上播放——内容宿主是 `QTabWidget` 时只动 `currentWidget()`，阶段条、页头与内容宿主本身不位移。触发点收敛在 `WorkspaceBinding.sync()`：它本来就在真正切页后同步页头与阶段条，现在在 `set_current_stage()` / `show_utility()` 之后顺带播放过渡；“测量进行中一律瞬时”由绑定层用注入的 controller 判断（`_measurement_idle()`），窗口保持只装配、不新增动画入口，`main_window.py` 仍在 750 行门禁内。方向只消费一次，重复同步同一页不会重播；每次新过渡先停止并摘除上一条，`set_content()` 与 `set_animations_enabled(False)` 也会收尾。首次显示与从测试配置页进入的切换不播放；旧页由标签宿主立即隐藏，不做双页快照。离屏逐帧检查发现 matplotlib 画布是原生子窗口、不会被效果快照捕获，半透明阶段会透出效果输出下面的黑底；因此 `SlideFadeEffect` 增加可选 `background`，测量页过渡先以 `TOKENS["canvas"]` 铺满控件矩形再合成快照，淡入始终发生在页面底色上（不给底色时行为与步骤 2 完全一致）。
- **验证**：`tests/ui/test_motion.py` 覆盖底色铺满与半透明合成；`tests/ui/test_measurement_workspace.py` 覆盖前进/后退方向、非阶段切换、自定义阶段集合、真实 `SlideFadeEffect` 挂载与 10px 起始偏移、页面底色、重复同步不重播、`animate=False` 与动效关闭、换内容收尾；`tests/integration/test_main_window_flow.py` 覆盖真实窗口按阶段顺序请求过渡、进入配置页不播放、动效开关关闭、测量进行中瞬时切换、新过渡取消旧过渡，以及可见窗口下过渡结束不残留效果。离屏逐帧抽查确认 matplotlib 页面在过渡中不再闪黑。`tools/run_tests.py --layer ui` 1325 项通过；`tools/run_tests.py --layer integration`（153 项集成 + 1325 项 UI + 402 项仓库门禁）通过。步骤 13 完成。
- **验收**：切页有 220ms 淡入 + 10px 位移；阶段条/页头/左栏不动；测量中切页瞬时；动画结束无残留效果。
- **测试**：`--layer ui` + `--layer integration`；手动离屏/真机各看一次切页。

- **技术决定**：
  - 发丝线是状态指示，不替代状态面板里的详细进度条，也不新增数值来源。
  - 用一个共享的 `QVariantAnimation` 驱动呼吸点，不为每个阶段各起一个计时器；空闲时停止，避免后台 CPU。
  - 不做结果表逐行 stagger：`QTableWidget` 行级动画成本高、收益低；结果面整体一次淡入已经足够。
  - 完成态只在状态从 ACTIVE 变为 COMPLETED 时播放一次；重复进入页面不重播。
- **已落地决定**：
  - 发丝线是 `MeasurementProgressHairline`（`measurement_workspace.py`）：固定 2px 高并常驻占位，不因显示/隐藏推动内容区；有活动测量时画轨道与已走段，空闲时保持空白。进度只接受 0–100 的数值并夹紧，`bool`/字符串等非法载荷被拒绝，激活新测量时归零。
  - 活动态与进度都收敛到 `WorkspaceBinding`：`observe_measurement_state()` 写 `set_measurement_active(state.is_active)`，构造函数把 controller 的 `signals.progress` 接到 `observe_progress()`；假 controller 没有 progress 信号时静默跳过。`start_session()` 与换 run 的 `_sync_run_state()` 同时收起发丝线。
  - 阶段条用两条共享动画：`_pulse_animation`（`MOTION_BREATH_MS` 循环，所有 ACTIVE 项共用）与 `_sweep_animation`（`MOTION_COMPLETE_MS`，同一时刻只有一个目标）。按钮只保存呼吸相位与扫过进度，`QAbstractButton` 的几何与布局完全不变。
  - 停机的判定集中到 `_micro_motion_allowed()`（动效开启 + 阶段条可见 + 有当前阶段）：呼吸点再要求存在 ACTIVE 项；完成扫过还要求目标 `display_state()` 仍是 COMPLETED，所以停用阶段不会扫、配置页不会扫。目标被写离完成态（换 run 清回 PENDING）或停用时扫过立即收尾；`hideEvent` 同时停止指示块、呼吸与扫过。完成扫过只在 `set_state` 观察到 ACTIVE → COMPLETED 时触发，重复写入同一状态不重播；FAILED/STOPPED 只更新状态色，不启动任何动画。
  - 发丝线对 `bool`/字符串抛 `TypeError`，对 `NaN`/`±inf` 抛 `ValueError`（无法夹紧）；`WorkspaceBinding.observe_progress()` 在信号槽边界静默丢掉这两类载荷，保证“同步入口不抛异常”，已有的有效进度不会被非法值改写。
  - `MOTION_BREATH_MS = 1600` 与其他动效时长一起放在 `theme.py`，并由 `tests/ui/test_motion.py` 与其余动效令牌一起冻结；完成扫过复用既有 `MOTION_COMPLETE_MS`，没有新增颜色值。
- **验证**：`tests/ui/test_measurement_workspace.py` 覆盖发丝线占位高度、活动/空闲像素（空闲整条线只有一个颜色）、进度夹紧、非法载荷与 `NaN`/`±inf` 拒绝、激活归零、迟到的空闲进度被忽略、显示/隐藏不推动常驻框架；`tests/ui/test_measurement_stage_rail.py` 覆盖 ACTIVE 启动共享呼吸动画、STOPPED/FAILED 停机、ACTIVE→COMPLETED 只扫一次、PENDING→COMPLETED 不扫、配置页与停用阶段不扫、换 run 清回未开始后立即停扫、扫过中途关闭动效、清空当前/隐藏阶段条与停用阶段停机；`tests/ui/test_workspace_binding.py` 覆盖 progress 与活动态写穿、非法载荷（含 `NaN`/`±inf`）忽略、无 progress 信号的 controller；`tests/integration/test_main_window_flow.py` 覆盖真实窗口的发丝线/呼吸接线、完成扫过一次、切到配置页停止、配置页期间完成不扫、窗口关闭停止呼吸；`tests/ui/test_motion.py` 冻结 `MOTION_BREATH_MS`。`tools/run_tests.py --layer ui` 1349 项通过；`tools/run_tests.py --layer integration` 406 项通过；全量离线 4280 项通过（8 跳过）；`launcher.py --check` 与 `launcher.py --validate-config` 通过。

### 阶段五：可选增强（不阻塞主线）

#### 步骤 15（可选）：阶段摘要与结果 KPI

- **范围**：三个测量页各加一个窄方法（如 `stage_summary()` / `stage_metrics()`），工作台页头和阶段条消费。
- **工作量**：中（三页各一处取数 + 排版）。
- **执行策略**：页面从自己已经显示的数据里返回“频点数/当前频点/最近更新时间”或四项 KPI；工作台只负责排版，不做计算。
- **技术决定**：摘要必须来自页面现有数据，不新增业务查询；没有数据时显示“未开始”，不显示 0 或假值。完成后阶段条可显示“6 频点”，结果面可显示 KPI 行。
- **已落地决定**：
  - 新增纯 Python 契约 `presentation/qt/stage_summary.py`：不可变 `StageMetric(label, value)`、`StageSummary(headline, metrics)`，以及 `frequency_headline` / `frequency_text` / `count_text` 三个纯格式函数；没有数据时统一返回 `NOT_STARTED`（“未开始”）。契约本身保证两句话一致：`headline` 为“未开始”时 KPI 不得携带数量，有数据时至少有一项 KPI，避免阶段条与结果面对不上。模块不导入 Qt，已登记进 `QT_FREE_PRESENTATION_MODULES`。
  - 三个测量页各实现只读 `stage_summary()`，只读自己已经显示的数据：线损页取表格行数、选中/最后一行频率与有值的线缆列；驱动映射页与功放页取实时缓存的频点数、当前浏览频点与最长扫频曲线点数。没有新增结果 DTO、业务查询或仪器读取。
  - 线损页把表格的 `itemSelectionChanged` 接到摘要刷新：选中行决定“当前频点”，KPI 行与页头必须随选择变化，而不是只在下次查询时读到新值；取消选择回落到最后一行。
  - 页面数据变化时（实时点、清空、加载结果、频点浏览、选中行）调用 `_refresh_stage_summary()`：更新结果面 KPI 行并发出 `stage_summary_changed`。三页各自缓存上一份已展示摘要，摘要没变化就不重排控件、不发信号；批量载入结果仍先暂停逐行刷新，循环结束后只刷新一次。结果面 KPI 行是共享的 `StageMetricsRow`（在 `measurement_surface.py` 内复用单元，只排版标签与值），标签用 `hint` 角色、值用既有 `measurementMetric` 样式，不新增颜色或字号。
  - `WorkspaceBinding` 在构造时连接每个页面的 `stage_summary_changed`，在 `sync()` 切回阶段页时重新拉取一次；`refresh_summaries()` 可整体刷新。未知 key、非阶段页、缺失方法、非法载荷或读取异常都静默忽略，保留上一个有效摘要，信号槽不抛异常。
  - `MeasurementWorkspace` 按 key 保存摘要：阶段条显示 `headline`（如“6 频点”），页头右侧只在当前阶段有数据时显示一份紧凑 KPI 文本；切回该阶段会重新显示保存的摘要。工具页（测试配置）与无数据状态不占用页头行高，常驻框架的几何仍不随阶段切换移动。
- **验证**：`tests/ui/test_stage_summary.py` 覆盖纯契约、空态、非法格式与“未开始不得携带数量 / 有数据至少一项 KPI”；`tests/ui/test_measurement_surface.py` 覆盖 KPI 行复用、隐藏与样式角色；三个页面测试覆盖空态、频点/当前频点/线缆或扫频点、选中行刷新与回落、频点浏览、清空、摘要去重与 `stage_summary_changed`；线损页另覆盖批量载入只刷新一次；`tests/ui/test_measurement_workspace.py` 覆盖阶段条/页头摘要、切回阶段恢复、工具页隐藏与空态；`tests/ui/test_workspace_binding.py` 覆盖切页拉取、页面信号、非法/缺失摘要与整体刷新；`tests/integration/test_main_window_flow.py` 覆盖真实窗口里页面数据显示到阶段条/页头、选中行改变当前频点、清空后回到“未开始”。`tools/run_tests.py --layer ui` 1397 项通过；`tools/run_tests.py --layer integration` 407 项通过；全量离线 4329 项通过（8 跳过）；`launcher.py --check` 与 `launcher.py --validate-config` 通过。
- **验收**：摘要与实际表格/曲线一致；选中行改变当前频点时页头立即跟随；空态不误导；重复数据不产生多余刷新；不影响测量启动。

**不列入本计划、另行评估**：把三个测量页合并成一个常驻测量台（外壳拥有左栏和控制面，右侧只替换结果面，`StatusPanel` 不再在页面间 `unmount/mount`）。它的收益是彻底消除切页时的左栏重挂，但会改变页面构造与测试边界，工作量明显大于前 14 步；只有前 14 步落地后仍觉得左栏闪烁，或产品明确要求“一个控制台”时，再单独立项。

## 8. 风险与回退
