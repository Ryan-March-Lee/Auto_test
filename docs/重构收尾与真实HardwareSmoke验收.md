# 第一期与第二期重构收尾及真实 Hardware smoke 验收

## 1. 当前结论

第一期“清理 `enhanced_workers` 职责”和第二期“GUI 页面与 `MeasurementController` 重构”的代码及离线验收均已完成。

当前唯一未完成事项是现场真实 Hardware smoke，包括线损、驱动功率映射和主功放三类完整测量。未取得现场授权、设备信息和安全窗口前，不得执行真实 RF 或电源动作，也不得将离线测试或历史 `minimal_action` 结果视为完整现场验收。

当前状态应描述为：**两期重构离线验收完成，真实 Hardware smoke 待现场条件具备。**

## 2. 已完成内容

- `enhanced_workers.py` 及其生产兼容入口已删除；结果仓储、应用测量用例和 Qt worker 已按职责分层。
- `CableLossPage`、`DriverMappingPage`、`AmplifierPage` 已拆分为独立页面对象。
- `MeasurementController` 已统一三类测量的启动、停止、紧急停止、线损继续、状态转发和 worker 终态清理。
- `MainWindow` 通过应用组装层和 worker factory 接入测量链路，不直接实例化三类测量 worker。
- 页面、状态对象、controller、worker、窗口组合和架构依赖均已完成离线回归；页面不直接访问 VISA、SCPI、结果存储或具体测量服务。
- 硬件默认边界已固定为：

  ```text
  应用入口 / 测量服务
          ↓
  measurement_port
          ↓
  SafetyInstrumentSession
          ↓
  driver
          ↓
  transport
          ↓
  VISA 或仿真设备
  ```

- 已确认完成、异常、取消、停止、部分初始化和重复测量的离线安全清理；外部注入的 `measurement_port` 不由 controller 越权关闭。
- 已完成离线测试、应用依赖检查、配置校验、编译检查和架构审计。具体测试数量以最近一次实际执行结果为准，不在本文件重复维护历史数量。

## 3. 现场验收前置条件

现场执行前必须确认并记录：

1. 现场授权、设备连接、VISA 地址和设备身份。
2. 正式生产电源拓扑、设备角色、通道及上下电顺序。
3. DUT 保护条件、功率上限、低功率安全值、停止和紧急停止方案。
4. 线损数据、功率范围、频谱仪 marker 查询和驱动功放外部供电状态。
5. 本地配置版本和动作预算；地址、凭据及原始现场报告只保存在本机，不提交版本库。
6. Hardware smoke 安全门禁：使用 `.env` 中的 `AUTO_TEST_PYTHON`、本地非示例配置、`HARDWARE_SMOKE_ENABLED=1` 和 `-ConfirmHardwareSmoke`，且不得在 CI 执行。

smoke 可以通过 VISA 枚举并逐台验证符合条件且空载的 DP832A，但这种发现语义只用于受控设备能力和安全清理验证，不得推导生产角色、通道或上下电顺序。生产测量必须使用正式配置定义的明确拓扑。

## 4. 真实 Hardware smoke 执行顺序

按低风险到高风险的顺序执行：

1. **基础连接与清理 smoke**
   - 确认 RF 初始关闭、受检电源通道均关闭、设备身份匹配。
   - 验证连接、最小安全动作、异常清理和 VISA resource / ResourceManager 释放。
   - 无可用空载电源，或任一匹配 DP832A 的受检输出未关闭时，smoke 必须失败。
2. **线损测量**
   - 使用新应用组装路径执行，确认频率/功率单位、线损数据读取、结果范围和归档。
3. **驱动功率映射**
   - 确认驱动功放通道、DUT 通道、功率扫描顺序、外部供电条件和异常中止。
4. **主功放测量**
   - 确认功放计算、输入输出单位、功率限制和安全停机行为。

每类测量都必须覆盖正常完成、普通停止、紧急停止和测量异常后的重新连接。每次完成、异常或取消后，必须确认 RF 关闭、电源按 `Drain -> Gate` 顺序关闭、VISA 资源释放，且下一次测量不会复用已清理端口。

## 5. 现场证据与完成标准

每类测量至少保存脱敏报告、配置快照、设备身份、实际 SCPI 操作顺序、测量值、结果归档位置、异常记录和清理证据。现场原始敏感资料仅保存在本机。

只有同时满足以下条件，才能将两期状态更新为真实验收完成：

- 三类完整测量均由新应用组装路径完成，并有独立现场证据。
- 正常、停止、紧急停止、异常和重新连接路径均通过，设备最终处于 RF 关闭、电源输出关闭、连接资源释放状态。
- 现场确认生产电源拓扑、角色、通道、上下电顺序、功放供电条件和设备映射。
- Hardware smoke 及必要的真实测量没有未解释失败；现场报告、配置和回滚决定已归档。

现场验收完成后，补充执行日期、设备信息、结果、失败项、清理证据和回滚决定，再评估本文件归档或删除。
