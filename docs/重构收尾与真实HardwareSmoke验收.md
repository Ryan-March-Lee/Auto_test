## 3. 现场验收前置条件

本节是指南步骤 F1 的现场记录摘要，完整判定以指南 F1 为准。现场执行前必须逐项确认并记录；任一项未满足不得进入执行阶段。

1. 现场授权、设备连接、VISA 地址和设备身份。**未授权不得执行真实 RF 或电源动作。**
2. 正式生产电源拓扑、设备角色、通道及上下电顺序。smoke 可枚举并逐台验证符合条件且空载的 DP832A，但该发现语义只用于受控设备能力和安全清理验证，不得推导生产角色、通道或上下电顺序；生产测量必须使用正式配置定义的明确拓扑。
3. DUT 保护条件、功率上限、低功率安全值、停止和紧急停止方案。
4. 线损数据、功率范围、频谱仪 marker 查询和驱动功放外部供电状态。
5. 本地配置版本和动作预算；地址、凭据及原始现场报告只保存在本机，不提交版本库。
6. Hardware smoke 安全门禁：使用 `.env` 中的 `AUTO_TEST_PYTHON`、本地非示例配置、`HARDWARE_SMOKE_ENABLED=1` 和 `-ConfirmHardwareSmoke`，且不得在 CI 执行。
7. 运行契约就绪：线损、驱动映射和主功放使用已创建的 `run_id`，运行目录中的硬件配置快照校验通过，线损/驱动映射输入均由该运行 manifest 明确登记。不得从全局结果目录自动选取最新校准数据，也不得回退旧兼容测量入口或无路径读取。
8. 基础连接与清理 Hardware Smoke 只执行受门禁保护的设备安全测试，不创建运行目录；它不替代正式测量的运行契约。

## 4. 真实 Hardware smoke 执行顺序

本节是指南步骤 F2 至 F5 的现场执行摘要，完整验收标准以指南对应子步骤为准。按低风险到高风险的顺序执行。

1. **基础连接与清理 smoke（F2）**
   - 确认 RF 初始关闭、受检电源通道均关闭、设备身份匹配。
   - 验证连接、最小安全动作、异常清理和 VISA resource / ResourceManager 释放。
   - 无可用空载电源，或任一匹配 DP832A 的受检输出未关闭时，smoke 必须失败。
   - 不创建运行目录，不替代正式测量的运行契约。
2. **线损测量（F3）**
   - 使用新应用组装路径与已创建的 `run_id` 执行，确认频率/功率单位、线损数据读取、结果范围和归档。
   - 线损输入必须由当前运行 manifest 登记，不得从全局结果目录自动选取。
3. **驱动功率映射（F4）**
   - 确认驱动功放通道、DUT 通道、功率扫描顺序、外部供电条件和异常中止。
   - 运行输入来自当前运行 manifest 或显式路径，不得回退最新结果。
4. **主功放测量（F5）**
   - 确认功放计算、输入输出单位、功率限制和安全停机行为。
   - 运行输入来自当前运行 manifest 或显式路径，不得回退最新结果。

每类测量都必须覆盖正常完成、普通停止、紧急停止和测量异常后的重新连接。每次完成、异常或取消后，必须确认 RF 关闭、电源按 `Drain -> Gate` 顺序关闭、VISA 资源释放，且下一次测量不会复用已清理端口。

## 5. 现场证据与完成标准

本节是指南步骤 F6 的现场证据摘要，完整完成标准以指南 F6 为准。每类测量至少保存脱敏报告、配置快照、设备身份、实际 SCPI 操作顺序、测量值、结果归档位置、异常记录和清理证据。现场原始敏感资料仅保存在本机。

只有同时满足以下条件，才能将步骤 F 标记为归档：

- 三类完整测量均由新应用组装路径使用已创建的 `run_id` 完成，并有独立现场证据。
- 正常、停止、紧急停止、异常和重新连接路径均通过，设备最终处于 RF 关闭、电源输出关闭、连接资源释放状态。
- 现场确认生产电源拓扑、角色、通道、上下电顺序、功放供电条件、设备映射和运行契约。
- Hardware smoke 及必要的真实测量没有未解释失败；现场报告、配置和回滚决定已归档。

**F 归档后的强制交接（不得跳过或合并提交）**：

1. 按指南 C1 至 C4 停止正式测量写全局兼容副本，并逐项验证历史查看仍可用。**已完成（技术债步骤 2/3，2026-10-26）**
2. 按指南 E2 至 E4 退役旧兼容测量根入口及遗留再导出，逐项单独提交并更新发布清单。**旧入口已完成（技术债步骤 4，2026-10-26）；纯再导出模块按发布说明 10.4 独立退役**
3. 复跑 E5 门禁、全量离线测试、`launcher.py --check` 与 `launcher.py --validate-config`，并更新[兼容层弃用与删除发布说明](兼容层弃用与删除发布说明.md)。
4. 以上全部完成且本文件正式标记为最终验收记录后，才满足删除重构指南的条件。
