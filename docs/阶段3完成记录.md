新增能力：

- `ScpiSpectrumAnalyzerDriver` 支持中心频率、Span、RBW、VBW 配置，内部统一使用 Hz。
- 峰值测量按“选择峰值 -> 查询标记值”顺序执行，并将返回值解析为有限 `float` dBm。
- 空值、非数字和非有限测量结果抛出 `SpectrumAnalyzerMeasurementError`，同时兼容原有 `RuntimeError`/`ValueError` 捕获行为；transport 超时和通信异常保持原类型及上下文。
- 支持为频率、Span、RBW、VBW 注入可选设备范围；非法参数在任何 transport 操作前拒绝。
- `SpectrumAnalyzerActions` 显式转发连接、配置、测量和关闭动作，不拼接 SCPI、不创建 VISA 连接。
- 保留 `configure_center_frequency_hz`、`configure_bandwidth_hz` 和 `measure_power_dbm` 旧端口兼容别名。
- 使用 Mock transport 验证配置、查询、返回值解析、异常、超时传播、非法参数不发送和 action -> driver -> transport 最小链路。
