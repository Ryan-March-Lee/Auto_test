新增能力：

- 增加新 driver/`SafetyInstrumentSession` 到既有测量服务协议的兼容适配器。
- 明确 Hz、GHz、MHz、dBm 和电源通道的边界转换。
- 适配器支持显式区分 DUT 与驱动功放的 gate/drain 通道，并拒绝通道重叠。
- 统一清理接口兼容 `close_all(close_rf=False)`，并保证 RF、驱动电源、DUT 电源和连接的清理顺序。
- 线损、驱动映射、主功放增强包装器和三个历史测量类均要求显式注入 `measurement_port`；生产 GUI 不再提供 legacy 组装入口，`InstrumentControl` 仅作为历史模块和安全回归测试保留。
- 第一层通过模拟 driver/session 验证服务能力映射、动作顺序、安全关闭和异常清理。
- 第二层继续使用 `tests/simulation` 的完整流程和故障清理测试。
- 第三层沿用 `run_hardware_smoke.ps1` 独立门禁；本次未连接真实设备。

迁移的旧调用方：

- 测量服务仍接受历史 `set_frequency`、`set_power` 等能力名。
- 新实现通过各测量包装器的 `measurement_port` 参数接入，历史 `InstrumentControl` 不再由应用组装层调用。
- 当前正式 GUI 使用新硬件组装入口；旧 GUI worker 和生产 legacy 组装入口已删除。
- 新增 `create_measurement_port(mode="simulation")` 离线组装入口；生产端仅支持 `hardware` 和 `simulation` 两种组装模式。
- `app/gui_runtime.py` 提供显式离线端口创建函数和硬件组装入口，真实设备 GUI 默认已切换到新组装路径。

所有测量类缺少端口时会拒绝构造，避免现代路径意外回退；历史控制器仅由独立历史测试直接覆盖。
