新增能力：

- 增加新 driver/`SafetyInstrumentSession` 到既有测量服务协议的兼容适配器。
- 明确 Hz、GHz、MHz、dBm 和电源通道的边界转换。
- 适配器支持显式区分 DUT 与驱动功放的 gate/drain 通道，并拒绝通道重叠。
- 统一清理接口兼容 `close_all(close_rf=False)`，并保证 RF、驱动电源、DUT 电源和连接的清理顺序。
- 线损、驱动映射、主功放包装器新增可选 `measurement_port` 注入点；未注入时继续使用旧 `InstrumentControl`。
- 第一层通过模拟 driver/session 验证服务能力映射、动作顺序、安全关闭和异常清理。
- 第二层继续使用 `tests/simulation` 的完整流程和故障清理测试。
- 第三层沿用 `run_hardware_smoke.ps1` 独立门禁；本次未连接真实设备。

迁移的旧调用方：

- 测量服务仍接受历史 `set_frequency`、`set_power` 等能力名。
- 新实现通过各测量包装器的 `measurement_port` 参数接入，旧 `InstrumentControl` 可继续回滚使用。
- 当前 GUI 默认仍使用旧入口；迁移组装层时传入 `PortMeasurementAdapter` 即可切换，避免隐式改变现场设备行为。
- 新增 `create_measurement_port(mode="simulation")` 离线组装入口；`mode="legacy"` 明确保留旧控制器回滚路径。
- `app/gui_runtime.py` 提供显式离线端口创建函数，真实设备 GUI 默认组装不变。

回滚方式：不传入 `measurement_port` 即回到现有 `InstrumentControl` 路径；如需完全撤销，可删除适配器及其测试，现有服务和旧入口仍保持可用。
