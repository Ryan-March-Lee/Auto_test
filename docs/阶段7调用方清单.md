# 阶段 7 调用方清单

本清单对应《SCPI 控制架构重构指南》7.1。真实设备 GUI 与 worker 默认已切换到硬件组装路径；旧 `InstrumentControl` 保留为显式兼容/回滚路径。新默认路径的硬件 smoke 尚未执行，不代表最终验收完成。

| 调用方 | 当前入口 | 迁移目标 | 当前回滚方式 |
| --- | --- | --- | --- |
| `measurement_services.py` | `MeasurementInstrumentPort` 历史能力名 | `PortMeasurementAdapter` | 传入旧 `InstrumentControl` |
| `cable_loss_measurement.py` | `measurement_port or InstrumentControl` | 保留兼容层构造器回退 | 不传 `measurement_port` |
| `driver_power_mapping.py` | `measurement_port or InstrumentControl` | 保留兼容层构造器回退 | 不传 `measurement_port` |
| `amplifier_measurement.py` | `measurement_port or InstrumentControl` | 保留兼容层构造器回退 | 不传 `measurement_port` |
| `enhanced_workers.py` | worker 使用应用组装端口 | 仅接收显式注入端口；缺少端口直接拒绝 | 由 `app.gui_runtime.create_legacy_*_measurement()` 组装旧控制器 |
| `app/gui_runtime.py` | `connect_instruments()` 使用硬件工厂 | 新组装层默认；`connect_instruments_legacy()` 回滚 | 调用显式 legacy 入口 |
| `enhanced_main_gui.py` | 正式 worker 由 GUI runtime 组装端口 | 连接及测量入口使用新链路 | 显式调用 legacy 兼容入口 |
| `tests/simulation` | 直接创建模拟 session | 继续验证新 session 和适配器 | 删除注入即可回到旧端口测试 |
| `tests/test_*` | 旧入口兼容测试 | 新旧路径并行验证 | 保留旧测试和构造器默认值 |

## 旧入口审计

- 业务服务不导入 VISA resource，也不拼接 SCPI；旧 SCPI 只留在 `InstrumentControl`。
- 兼容适配器只做单位、通道和生命周期转换，不承载测量计算。
- `hardware` 是真实应用工厂默认模式；`simulation` 和 `legacy` 必须显式选择。
- `minimal_action` 已完成一次真实硬件 smoke，但该证据不覆盖本次硬件组装入口；本次迁移后须复跑 smoke，因此当前不删除 `InstrumentControl`。
- 三个增强测量包装器不再把缺少 `measurement_port` 当作旧控制器回退；兼容入口集中在 `app.gui_runtime.create_legacy_*_measurement()`，组装失败时关闭其自身创建的端口。
