# 阶段 7 调用方清单

本清单对应《SCPI 控制架构重构指南》7.1。现代 GUI 与 worker 的主要入口已切换到硬件组装路径；旧 GUI worker 有显式 legacy 组装入口，三个历史测量类现已要求显式注入端口。新默认路径的完整测量类型硬件验收尚未执行，不代表最终验收完成。

| 调用方 | 当前入口 | 迁移目标 | 当前回滚方式 |
| --- | --- | --- | --- |
| `measurement_services.py` | `MeasurementInstrumentPort` 历史能力名 | 由 `PortMeasurementAdapter` 实现并注入 | 显式注入 legacy 端口适配器 |
| `cable_loss_measurement.py` | 历史测量类要求显式注入端口 | 新 GUI 通过组装入口注入端口 | 明确调用 `create_legacy_cable_loss_measurement()` |
| `driver_power_mapping.py` | 历史测量类要求显式注入端口 | 新 GUI 通过组装入口注入端口 | 明确调用 `create_legacy_driver_mapping_measurement()` |
| `amplifier_measurement.py` | 历史测量类要求显式注入端口 | 新 GUI 通过组装入口注入端口 | 明确调用 `create_legacy_amplifier_measurement()` |
| `enhanced_workers.py` | worker 使用应用组装端口 | 仅接收显式注入端口；缺少端口直接拒绝 | 由 `app.gui_runtime.create_legacy_*_measurement()` 组装旧控制器 |
| `app/gui_runtime.py` | `connect_instruments()` 使用硬件工厂 | 新组装层默认；`connect_instruments_legacy()` 回滚 | 调用显式 legacy 入口 |
| `enhanced_main_gui.py` | 正式 worker 由 GUI runtime 组装端口 | 连接及测量入口使用新链路 | 显式调用 legacy 兼容入口 |
| `tests/simulation` | 直接创建模拟 session | 继续验证新 session 和适配器 | 删除注入即可回到旧端口测试 |
| `tests/test_*` | 新旧路径契约及历史 `InstrumentControl` 测试 | 覆盖显式新旧组装、所有权和失败清理 | 旧控制器继续保留；无依据不删除历史测试 |

## 旧入口审计

- 业务服务不导入 VISA resource，也不拼接 SCPI；旧 SCPI 只留在 `InstrumentControl`。
- 兼容适配器只做单位、通道和生命周期转换，不承载测量计算。
- `hardware` 是真实应用工厂默认模式；`simulation` 和 `legacy` 必须显式选择。
- `minimal_action` 已完成独立入口和新应用组装路径的真实硬件 smoke。smoke 只验证能发现并逐台控制空载仪器、电源基础动作和安全清理，不推导生产电源角色或业务测量正确性；该证据不覆盖 cable loss、driver mapping 和 amplifier 的完整测量类型验收。
- 三个增强测量包装器和三个历史测量类不再把缺少 `measurement_port` 当作旧控制器回退；兼容入口集中在 `app.gui_runtime.create_legacy_*_measurement()`，组装失败时关闭其自身创建的端口。
- 离线审计确认 `app/` 服务组装代码不直接使用 VISA/SCPI；VISA 创建集中在 `instrument/measurement_factory.py`，硬件 smoke 脚本属于独立门禁。本次独立 `minimal_action` 入口已通过；smoke 路径动态发现所有空载 DP832A 并逐台完成基础控制/安全关闭，但不定义生产电源拓扑。正式生产流程必须由配置和业务逻辑明确每台电源的角色、通道及上下电顺序，不得依赖发现顺序或默认广播；本清单不替代具体测量动作验收。
- 代码审查确认默认硬件工厂以 `SafetyInstrumentSession` 作为硬件协调边界，独立 action/flow 作为可复用安全组件保留；GUI 端口生命周期和历史测量类隐式回退已收束，历史模块独立脚本入口已删除。完整测量类型验收及生产电源拓扑、功放供电条件确认完成前，不得删除兼容代码或过程文档。
